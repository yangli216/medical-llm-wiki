# 中国医学权威指南与标准 LLM Wiki 本地知识库 (Medical LLM Wiki)

> **基于 Andrej Karpathy 提出的 [LLM Wiki 架构理念](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) 构建**  
> 告别传统 RAG 的“碎片化单次拼接”，通过大语言模型与编译器将中国权威医学临床指南编译沉淀为**持久化、相互勾连、复合演进的高质量本地 Markdown 知识库**。

---

## 一、 为什么选择 LLM Wiki 架构？

传统基于向量数据库的 RAG（检索增强生成）模式存在致命弊端：**每次提问时模型都要重新在散乱文档切片中盲人摸象，缺乏知识的预编译、跨文档沉淀与冲突校验**。

本项目遵循 Karpathy 的核心原则：
* **原始来源不可变 (Raw Sources Layer)**：官方发布的指南原文作为“唯一真实数据源”，只读归档；
* **知识库持久演化 (The Compiled Wiki Layer)**：将庞杂的指南条款提炼为实体（疾病、药物、机构）、概念（诊断切点、评分量表）以及综合专题（多病共管、用药禁忌），并构建数以百计的双向互联网络（`[[WikiLinks]]`）；
* **工具链与规范约束 (Schema & Tooling Layer)**：自动化保障零死链、零孤岛，并配套毫秒级 SQLite FTS5 全文检索、跨指南问答与交互式知识图谱浏览器。

## 四、 快速使用指引

### 1. 与 Obsidian 无缝联动
本知识库采用原生 Markdown + YAML Frontmatter + `[[WikiLink]]` 标准构建：
1. 打开 **Obsidian**；
2. 选择 **“打开已有仓库 (Open folder as vault)”**；
3. 选择目录 `/Users/yangli/Documents/llm`；
4. 即可在 Obsidian 中使用交互式**全局知识图谱 (Graph View)**、双链回溯、出入度统计与反向引用！

### 2. 命令行工具 (CLI) 指引

本项目工具链纯基于 Python 标准库与内置 SQLite FTS5，**无需额外安装庞大依赖**，开箱即用：

#### 查看知识库状态与统计
```bash
python3 -m tools.cli status
```
*输出：已收录 10 部权威文献、编译 50 篇词条、448 条双向链接、连接密度 0.1829、0 孤岛页面。*

#### 知识库质量体检 (Lint)
```bash
python3 -m tools.cli lint
```
*对全库进行静态扫描，确保 0 死链、0 孤岛、元数据字段规范及原始源引用闭环。*

#### 全文检索与高亮匹配 (Search)
```bash
python3 -m tools.cli search "降压 靶器官"
python3 -m tools.cli search "奥希替尼"
```

#### 跨指南临床智能研判问答 (Ask)
```bash
python3 -m tools.cli ask "高血压合并心力衰竭如何选药？"
python3 -m tools.cli ask "急性脑梗死溶栓时间窗是多少？"
```
*自动检索最相关的指南与实体，生成具备结构化要点与精确条目导航的综合研判报告。*

#### 启动本地 Web 可视化知识库服务 (Serve)
```bash
python3 -m tools.cli serve --port 8080
```
在浏览器中访问 [http://127.0.0.1:8080](http://127.0.0.1:8080)：
* 🕸️ **力导向知识图谱 (Force-Directed Graph)**：直观查看疾病、药物、概念、综合专题间的拓扑连接；
* 📄 **沉浸式阅读器**：阅读带双向链接高亮跳转的排版页面；
* 🔍 **毫秒级即时检索**：输入关键词实时展示联想匹配。

### 3. 运行自动化测试
```bash
python3 -m unittest discover tests
```

## 五、 知识库关键综合专题与临床安全红线沉淀

LLM Wiki 的最大价值在于将多部指南中隐藏的冲突与交叉点进行显性化综合沉淀：

1. **心脑代谢共病综合管理 (`wiki/synthesis/心脑血管与代谢性疾病共病管理.md`)**：
   - 梳理血压（<130/80）、血糖（HbA1c<7.0%）、血脂（LDL-C<1.4）、抗栓二级预防的“四高协同”；
   - 明确 SGLT2 抑制剂在降糖合并心衰/肾病中的跨界优先地位。
2. **临床用药六大致命红线规避 (`wiki/synthesis/慢病多药联合安全与禁忌规避.md`)**：
   - **红线 1**：ACEI 与 ARB 严禁联合（增加高钾血症与肾衰竭风险）；
   - **红线 2**：ACEI 换用 ARNI 必须停药至少 36 小时（规避致死性喉头血管神经性水肿）；
   - **红线 3**：二甲双胍在含碘造影剂检查前后停用 48 小时（规避乳酸酸中毒）；
   - **红线 4**：脑梗死溶栓后 24 小时内严禁抗血小板或抗凝治疗（规避脑出血转化）；
   - **红线 5**：SGLT2 抑制剂大手术前停药 3~4 天（规避正常血糖性酮症酸中毒）；
   - **红线 6**：螺内酯等保钾利尿剂在肾功能不全时的血钾严密监测。
3. **慢阻肺与心血管共病联合诊治 (`wiki/synthesis/慢阻肺与心血管共病联合诊治.md`)**：
   - 纠正历史观念误区：明确稳定性慢阻肺合并心衰患者**安全推荐高选择性 β1 阻滞剂（比索洛尔、美托洛尔）**，不仅不诱发气道痉挛，反而显著降低死亡率。
4. **恶性肿瘤转化治疗与 MDT 决策 (`wiki/synthesis/恶性肿瘤转化治疗与MDT决策路径.md`)**：
   - 肝癌（TACE/HAIC+靶免）、直肠癌（TNT与观察等待）、肺癌（新辅助免疫化疗）从不可切除到根治性切除的降期路径。
5. **临床感染经验性治疗降阶梯 (`wiki/synthesis/临床感染经验性治疗降阶梯与抗菌药物合理应用.md`)**：
   - “先送检、后用药”，48~72 小时根据微生物药敏坚决降阶梯为窄谱抗菌药物。

## 六、 持续扩展与维护机制

当国家卫生健康委或中华医学会发布新指南时，请严格参考 [`schema/INGEST_GUIDE.md`](schema/INGEST_GUIDE.md) 执行 7 步法入库：
1. 注册元数据到 `raw/metadata.json` 并保存原文到 `raw/docs/`；
2. 撰写 `wiki/sources/` 结构化解读页；
3. 更新或新建 `wiki/entities/` 疾病与药物实体；
4. 编写 `wiki/concepts/` 概念与量表；
5. 沉淀或修订 `wiki/synthesis/` 综合专题；
6. 同步更新 `wiki/index.md` 并向 `wiki/log.md` 追加流水；
7. 运行 `python3 -m tools.cli lint` 确认 0 错误后提交。
