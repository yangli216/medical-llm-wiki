# 中国医学权威指南与标准知识库 (Medical LLM Wiki)

欢迎访问 **Medical LLM Wiki** 本地知识库。本知识库基于 Andrej Karpathy 提出的 **LLM Wiki** 架构设计思想构建，面向中国权威医学机构（国家卫生健康委员会、中华医学会、中华医学会全科医学分会等）发布的国家级临床诊疗指南与行业标准进行知识编译与维护。

## 2. 疾病与健康主诉实体库 (Diseases & Conditions)

### 全科常见未分化主诉与老年共病
- [[良性阵发性位置性眩晕]]：全科眩晕首位病因（占40%以上），Dix-Hallpike试验，Epley手法复位，规避滥用输液。
- [[慢性咳嗽]]：咳嗽>8周且胸片正常，首要停用ACEI降压药，CVA/UACS/GERC解剖学阶梯诊断，严禁滥用抗菌药。
- [[非特异性腰痛]]：门诊腰痛85%~90%，马尾综合征红旗征紧急排查，严格限制卧床≤48小时，短期NSAIDs与核心运动。
- [[老年多病共存]]：65岁以上老年人患病率达70%，多病指南叠加困境，多重用药危害与以全人功能为中心管理。

### 常见重大慢性疾病与恶性肿瘤
- [[原发性高血压]]：成人患病率27.5%，分级分期分型，强化降压达标（<130/80）与靶器官保护。
- [[2型糖尿病]]：成人患病率11.2%，以患者为中心，二甲双胍基石与心肾保护前置。
- [[动脉粥样硬化性心血管疾病]]：ASCVD总体危险评估，LDL-C致病因子，长期降脂与抗血小板二级预防。
- [[急性ST段抬高型心肌梗死]]：STEMI胸痛急救，D2B≤90分钟，直接PCI与强化双联抗血小板。
- [[慢性心力衰竭]]：心脏疾病终末期，四种临床表型，“新四联”逆转心室重构。
- [[急性缺血性脑卒中]]：致死致残首位病因，“时间就是大脑”，静脉溶栓与血管内取栓。
- [[慢性阻塞性肺疾病]]：40岁以上患病率13.7%，气流受限不可逆，双支扩与戒烟干预。
- [[社区获得性肺炎]]：常见呼吸系统感染，胸部影像确诊，CURB-65分层收治与降阶梯。
- [[慢性肾脏病]]：CKD早期双筛（eGFR+UACR），CGA精细分期，四大支柱药物延缓透析。
- [[痛风与高尿酸血症]]：SUA>420统一阈值，小剂量抗炎镇痛，分层达标（<360/<300）与HLA-B*5801安全筛查。
- [[幽门螺杆菌感染]]：I类致癌物，证实感染即根除，14天铋剂四联与UBT质控。
- [[原发性肝癌]]：第4位高发恶性肿瘤，HBV肝硬化背景，CNLC分期与免疫联合转化切除。
- [[非小细胞肺癌]]：发病与致死首位肿瘤，LDCT年度筛查，驱动基因靶向分代与免疫联合。
- [[结直肠癌]]：消化道高发肿瘤，结肠镜金标准，高分辨直肠MRI与器官功能保留。
- [[乳腺癌]]：女性第一高发恶性肿瘤，免疫组化分子分型导向，HP双靶与CDK4/6抑制剂。

### 儿科、皮肤、耳鼻喉与精神心理疾病
- [[小儿急性支气管炎]]：儿童高发呼吸道感染，以病毒为主，止咳化痰，严格限制无指征抗菌药与中枢镇咳药。
- [[儿童肺炎支原体肺炎]]：学龄期高发，剧烈阵发性干咳伴发热，肺部体征轻与影像实变不平行，阿奇霉素一线及MRMP二线权衡。
- [[儿童支气管哮喘]]：呼气相高调哮鸣与夜间咳嗽，可逆性气流受限，压缩泵雾化解痉与维持期ICS基石，彻底漱口防鹅口疮。
- [[小儿急性腹泻病]]：儿童常见水样腹泻，脱水危险分层评估，低渗ORSIII口服补液与常规补锌，严禁洛哌丁胺。
- [[带状疱疹]]：水痘-带状疱疹病毒再激活，单侧节段性红斑水疱伴特征性神经痛，72小时黄金窗抗病毒与预防PHN。
- [[变应性鼻炎]]：特应性鼻黏膜IgE介导慢性炎性反应，喷嚏流涕鼻塞，鼻喷激素为基石，限制血管收缩剂≤7天。
- [[广泛性焦虑障碍]]：慢性心身障碍与未分化躯体症状（心悸胸闷头昏），GAD-7筛查，SSRI一线与BATHE心身沟通。

### 神经睡眠、骨科、眼科与消化动力疾病 (新增)
- [[失眠障碍]]：入睡潜伏期>30min与维持障碍，CBTI非药物一线首选，短程非苯二氮䓬类防成瘾。
- [[偏头痛]]：单侧搏动性剧烈头痛伴恶心畏光，发作期曲普坦类特异性止痛，缺血性心脑血管疾病绝对禁用。
- [[原发性骨质疏松症]]：中轴骨DXA T值≤-2.5或脆性骨折，钙与维D基础，双膦酸盐抗骨吸收与直立服药防食管炎。
- [[干眼症]]：泪膜稳态破坏伴眼干异物感，无防腐剂玻璃酸钠基础润滑，环孢素抗炎，严禁滥用缩血管眼药水。
- [[慢性功能性便秘]]：排便困难与频次<3次/周，器质性红旗征排查，渗透性(聚乙二醇)与容积性温和通便，禁长期滥用刺激性泻药。
- [[胃食管反流病]]：反酸烧心为典型表现，内镜洛杉矶分级，初始抑酸8周基石，莫沙必利促动力与铝碳酸镁抗酸吸附。
- [[血脂异常与高脂血症]]：成人患病率35.6%，ASCVD首要致病因素，LDL-C靶标导向，中等强度他汀联合依折麦布。
- [[急性单纯性尿路感染]]：女性高发急性单纯性膀胱炎，尿频急痛三联征，肾区叩痛阴性，呋喃妥因与磷霉素靶向抗菌。

### 妇科炎症、内分泌与耳鼻喉及呼吸常见病 (方案A专项新增)
- [[阴道炎与阴道微生态异常]]：门诊最高发妇科感染三联征（VVC/BV/TV），微生态镜检评价，妊娠期局部首选克霉唑，严禁口服氟康唑。
- [[甲状腺功能减退症]]：畏寒水肿脱发与反应迟钝，血清TSH升高确诊，左甲状腺素清晨空腹慢滴定，防金属螯合与心律失常。
- [[急性扁桃体炎]]：突发剧烈咽痛伴高热、扁桃体黄白脓点，Centor评分量化，阿莫西林足疗程10天根除链球菌防风湿热。
- [[急性上呼吸道感染]]：门诊最常见急性呼吸道感染，70%~80%病毒性自限性，对症退热镇痛为主，严格限制无指征抗生素。

## 3. 药物与疗法实体库 (Drugs & Therapies)

### 全科特色药物与适宜手法技术
- [[前庭抑制剂与耳石复位手法]]：Epley手法复位治愈BPPV，倍他司汀改善微循环，镇晕药严格限用3~5天防阻碍中枢代偿。
- [[慢性咳嗽阶梯治疗药物]]：ICS-LABA（布地奈德福莫特罗）、白三烯拮抗剂、第一代抗组胺减充血剂、抗反流双倍PPI。

### 核心专科与慢病用药
- [[二甲双胍]]：2型糖尿病绝对首选一线药物，全程保留，肾功能减退与造影停药规范。
- [[SGLT2抑制剂]]：达格列净/恩格列净，跨界降糖、心衰（HFrEF/HFpEF）与肾病保护基石。
- [[GLP-1受体激动剂]]：司美格鲁肽等，ASCVD极高危心血管保护与显著减重降糖。
- [[钙通道阻滞剂]]：氨氯地平等，降压强效平稳，老年高血压首选，与RAS抑制剂黄金联用。
- [[RAS抑制剂]]：ACEI与ARB，心肾微循环保护，降蛋白尿，严禁两类重叠联用。
- [[ARNI]]：沙库巴曲缬沙坦，心衰HFrEF首选及高血压推荐，ACEI转换必须间隔36小时。
- [[β受体阻滞剂]]：美托洛尔缓释片/比索洛尔，心衰新四联与交感亢进首选，慢阻肺安全选药。
- [[他汀类与PCSK9抑制剂]]：中等强度他汀为基础，依折麦布口服双联，PCSK9i注射强效达标。
- [[替格瑞洛与阿司匹林]]：STEMI与急性冠脉综合征双联抗血小板（DAPT）一线基石。
- [[降尿酸与抗炎药物]]：非布司他、别嘌醇（需筛基因）、苯溴马隆、小剂量秋水仙碱。
- [[铋剂四联抗幽门螺杆菌药物]]：PPI/P-CAB伏诺拉生 + 铋剂 + 2种抗生素（14天标准方案）。
- [[阿替普酶与替奈普酶]]：急性脑梗死与心梗溶栓特异性激活剂，脑梗溶栓后24小时严禁抗血小板。
- [[第三代EGFR-TKI]]：奥希替尼等，EGFR敏感突变晚期肺癌一线首选及术后辅助3年金标准。
- [[免疫检查点抑制剂]]：PD-1/PD-L1抗体，肝癌、肺癌、结直肠癌跨癌种一线突破。
- [[曲妥珠单抗与帕妥珠单抗]]：HER2阳性早期与晚期乳腺癌双靶治疗基石，T-DXd开拓低表达。
- [[CDK4与6抑制剂]]：哌柏西利/阿贝西利/达尔西利，HR+/HER2-晚期乳腺癌一线标准。
- [[限制与特殊级抗菌药物]]：呼吸喹诺酮、碳青霉烯类，主治/副主任处方权限与会诊制度。

### 儿科、皮肤与中西结合用药
- [[儿科呼吸与消化常用药物]]：盐酸氨溴索、小儿化痰止咳、低渗口服补液盐(ORSIII)、葡萄糖酸锌颗粒、双歧杆菌三联活菌。
- [[大环内酯类与儿童支原体治疗药物]]：阿奇霉素干混悬剂（间隙疗法）、盐酸多西环素片（$\ge 8$岁二线）、红霉素，QT间期延长警示。
- [[儿童哮喘吸入制剂与急救平喘药物]]：吸入用布地奈德混悬液、硫酸特布他林/沙丁胺醇、孟鲁司特钠咀嚼片，储雾罐使用规范。
- [[抗疱疹病毒与神经痛药物]]：盐酸伐昔洛韦（早期足量）、普瑞巴林（调节钙通道α2-δ阻断神经痛）、炉甘石洗剂。
- [[鼻喷激素与抗组胺药物]]：糠酸莫米松鼻喷剂（局部抗炎）、第二代抗组胺药（氯雷他定/左西替利嗪）、生理性海水喷雾。
- [[抗焦虑与抗抑郁药物]]：草酸艾司西酞普兰（SSRI一线抗焦虑抗抑郁）、劳拉西泮（短程过渡桥接防依赖成瘾）。
- [[经典中成药与中西结合合理用药]]：疏风解毒/连花清瘟/强力枇杷露，前置审查消渴丸含格列本脲、感冒灵含对乙酰氨基酚。

### 睡眠、头痛、骨病、眼科与通便药物 (新增)
- [[镇静催眠与促睡眠药物]]：右佐匹克隆、唑吡坦（非苯二氮䓬类短程≤4周），老年人避免长效地西泮防跌倒。
- [[偏头痛特异止痛与预防药物]]：佐米曲普坦、利扎曲普坦（早期特异性止痛，冠心病禁用），氟桂利嗪预防用药。
- [[抗骨质疏松与钙代谢药物]]：阿仑膦酸钠（晨起空腹立位30min）、碳酸钙D3片、骨化三醇，eGFR<35截断。
- [[眼科局部润滑与抗炎药物]]：玻璃酸钠滴眼液（高频首选单支无防腐剂包装）、0.05%环孢素滴眼液。
- [[肠道动力与缓泻通便药物]]：聚乙二醇4000散、乳果糖口服液、小麦纤维素颗粒，拦截蒽醌类刺激性泻药防黑变病。
- [[胃肠促动力药与胃黏膜保护剂]]：枸橼酸莫沙必利片（促食管胃排空）、铝碳酸镁咀嚼片（中和酸与吸附胆汁酸），餐后酸袋控制。
- [[尿路感染抗菌药物与对症解痉药]]：呋喃妥因肠溶片（尿液高浓度靶向杀菌）、磷霉素氨丁三醇散（3g单剂顿服）、碳酸氢钠片（碱化尿液对症解痉）。

### 妇科、内分泌与耳鼻喉咽痛药物 (方案A专项新增)
- [[妇科抗感染局部与外用药物]]：克霉唑阴道栓（VVC一线首选，孕期安全）、甲硝唑阴道泡腾片（BV/TV首选）、红核妇洁洗液。
- [[甲状腺激素与抗甲状腺药物]]：左甲状腺素钠片（优甲乐，清晨空腹口服，金属离子螯合间隔4h，老年/冠心病超小剂量滴定）、甲巯咪唑、丙硫氧嘧啶。
- [[青霉素类与咽扁桃体炎口服抗菌药物]]：阿莫西林胶囊（咽扁桃体炎GAS首选，足程10天）、青霉素V钾片、头孢羟氨苄胶囊（非严重过敏替代）。

## 5. 概念与诊疗规范 (Concepts)

### 全科医学服务模式与排雷质控
- [[全科以人为中心接诊与BATHE问诊技巧]]：生物心理社会模式，BATHE简易心理沟通五步法，捕捉隐匿就诊诉求。
- [[全科SOAP病历书写规范]]：问题导向病历（POMR），主观病感、客观查体、综合多轴评估与多元处置计划。
- [[老年多重用药筛查与处方精简五步法]]：多重用药筛查切点、中国版PIM标准、Beers/STOPP标准、处方精简操作。
- [[头晕眩晕HINTS三步床旁检查与红旗征]]：头脉冲(HIT)、眼震(Nystagmus)、偏斜(Skew)排查后循环中枢卒中。
- [[慢性咳嗽病因解剖学阶梯诊断路径]]：咳嗽>8周胸片正常，CVA -> UACS -> EB -> GERC 解剖学自上而下阶梯排查。
- [[腰痛红旗征排查与NEWS早期预警评分]]：马尾综合征等四大腰痛红旗征，国家早期预警评分NEWS六大生理参数分级。

### 专科诊断分期与评分量表
- [[高血压分级与靶器官损害评估]]：1/2/3级切点、家庭/动态血压标准、靶器官损害评估。
- [[2型糖尿病诊断切点与控制目标]]：静脉糖切点、HbA1c≥6.5%、个体化分层达标。
- [[ASCVD危险分层与LDL-C控制靶标]]：超高危<1.4、极高危<1.8、降幅≥50%与非-HDL-C计算。
- [[STEMI急诊绿色通道与直接PCI时效指标]]：FMC-ECG≤10min、D2B≤90min、D2N≤30min时效指标。
- [[CKD病因-GFR-白蛋白尿CGA分期]]：CGA联合分期矩阵、进展风险热图与用药调整界点。
- [[血尿酸分层达标与HLA-B5801检测]]：SUA>420、一般<360、痛风石<300、汉族人群别嘌醇基因筛查红线。
- [[幽门螺杆菌尿素呼气试验与耐药规范]]：13C/14C呼气试验停药质控规范与国内耐药谱策略。
- [[CURB-65肺炎严重度评分]]：5项量化指标判定30天死亡风险与门诊/住院/ICU分流。
- [[GOLD气流受限分级与ABE评估]]：FEV1%pred分级、ABE症状与急性加重风险矩阵。
- [[心力衰竭表型分型与利钠肽诊断阈值]]：HFrEF/HFmrEF/HFpEF/HFimpEF分类、NT-proBNP年龄切点。
- [[急性缺血性脑卒中静脉溶栓与取栓时间窗]]：4.5h溶栓、6-24h取栓指征、24h抗栓保护期。
- [[结直肠癌高危筛查与直肠MRI评估]]：初筛+FIT+结肠镜路径、CRM切缘与EMVI血管侵犯。
- [[CNLC中国肝癌临床分期]]：结合中国国情，Ia~IV期治疗路径决策树。
- [[肺癌TNM分期与驱动基因谱]]：I-IV期分期原则、EGFR/ALK/ROS1等全套靶点指引。
- [[乳腺癌免疫组化分子分型与HER2低表达]]：ER/PR/HER2/Ki-67四联分型、HER2低表达（IHC 1+或2+/FISH-）新范式。
- [[抗菌药物三级处方权限与围手术期预防规范]]：三级资质矩阵、I类切口0.5~1h与≤24h限时。

### 儿科与专科临床规范
- [[小儿脱水评估与补锌补液规范]]：小儿轻中重度脱水体征量化矩阵，低渗ORSIII少量多次补液与腹泻规范补锌10~14天。
- [[儿童支原体肺炎大环内酯耐药与二线药物权衡]]：72小时体温无下降MRMP耐药预警，8岁儿童年龄界点与新型四环素类超说明书知情。
- [[儿童哮喘急性发作严重度评估与阶梯控制]]：轻中重度发作量化评估、阶梯升降级标准、C-ACT控制评分与哮喘行动计划AAP。
- [[带状疱疹72小时黄金窗与PHN预防]]：出疹72h抗病毒黄金窗、高危因素（高龄/重痛/皮损重）、普瑞巴林早期中枢阻断。
- [[变应性鼻炎阶梯药物与减充血剂警示]]：间歇与持续分度阶梯用药、外侧壁正确喷药技巧、减充血剂防药物性鼻炎。
- [[中西药成分重叠与理化配伍禁忌]]：消渴丸+磺脲类致死低血糖、感冒灵+扑热息痛暴发肝坏死、金属离子抗生素螯合。

### 睡眠、头痛、骨病、眼科与通便规范 (新增)
- [[慢性失眠CBTI干预与镇静催眠药减停]]：刺激控制、睡眠限制、睡眠卫生与催眠药阶梯渐进减停防反跳。
- [[偏头痛发作期特异止痛与心血管禁忌]]：曲普坦类冠脉痉挛心梗红线、止痛药过度使用性头痛(MOH)阻断界点。
- [[骨密度DXA诊断切点与双膦酸盐给药规范]]：中轴骨T值诊断矩阵、晨起空腹白水立位30min食管保护与eGFR<35截断。
- [[干眼症眼表评估与眼用制剂防腐剂警戒]]：FBUT与Schirmer泪膜量化、苯扎氯铵防腐剂角膜毒性与单支剂型优选。
- [[便秘红旗征排查与刺激性泻药滥用警示]]：六大肿瘤报警征排查、蒽醌类神经丛损伤与结肠黑变病阻断。
- [[胃食管反流病洛杉矶分级与难治性反流排查]]：LA-A~D内镜严重度分级、服药时间核查、CYP2C19快代谢与P-CAB换药路径。
- [[下尿路感染鉴别诊断与抗菌药物靶向选用规范]]：下尿路感染与肾盂肾炎体征鉴别、尿液高浓度靶向口服药选用、阻断静脉大输液滥用。

### 妇科、内分泌与耳鼻喉临床规范 (方案A专项新增)
- [[阴道炎分型特征与微生态评价]]：VVC豆渣样/BV灰白稀薄胺味/TV黄绿泡沫三联鉴别，阴道pH与Nugent评分微生态量化。
- [[甲减TSH控制目标与左甲状腺素滴定规范]]：普通成人0.5~4.0、老年/冠心病放宽至4.0~7.0、孕早期<2.5，空腹吸收与金属离子螯合服药窗口。
