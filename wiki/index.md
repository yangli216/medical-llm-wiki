# 中国医学权威指南与标准知识库 (Medical LLM Wiki)

欢迎访问 **Medical LLM Wiki** 本地知识库。本知识库基于 Andrej Karpathy 提出的 **LLM Wiki** 架构设计思想构建，面向中国权威医学机构（国家卫生健康委员会、中华医学会等）发布的国家级临床诊疗指南与行业标准进行知识编译与维护。

知识库完全与 **Obsidian** 无缝兼容，所有词条均支持标准双向链接（如 [[原发性高血压]]）、层级标签及 YAML Frontmatter。

## 2. 疾病实体库 (Diseases)

- [[原发性高血压]]：成人患病率27.5%，分级分期分型，强化降压达标与靶器官保护。
- [[2型糖尿病]]：成人患病率11.2%，以患者为中心，二甲双胍基石与心肾保护前置。
- [[原发性肝癌]]：第4位高发恶性肿瘤，HBV肝硬化背景，CNLC分期与免疫联合转化切除。
- [[非小细胞肺癌]]：发病与致死首位肿瘤，LDCT年度筛查，驱动基因靶向分代与免疫联合。
- [[急性缺血性脑卒中]]：致死致残首位病因，“时间就是大脑”，静脉溶栓与血管内取栓。
- [[慢性阻塞性肺疾病]]：40岁以上患病率13.7%，气流受限不可逆，双支扩与戒烟干预。
- [[慢性心力衰竭]]：心脏疾病终末期，四种临床表型，“新四联”逆转心室重构。
- [[社区获得性肺炎]]：常见呼吸系统感染，胸部影像确诊，CURB-65分层收治与降阶梯。
- [[结直肠癌]]：消化道高发肿瘤，结肠镜金标准，高分辨直肠MRI与器官功能保留。

## 3. 药物与疗法实体库 (Drugs & Therapies)

- [[二甲双胍]]：2型糖尿病绝对首选一线药物，全程保留，肾功能减退与造影停药规范。
- [[SGLT2抑制剂]]：达格列净/恩格列净，跨界降糖、心衰（HFrEF/HFpEF）与肾病保护基石。
- [[GLP-1受体激动剂]]：司美格鲁肽等，ASCVD极高危心血管保护与显著减重降糖。
- [[钙通道阻滞剂]]：氨氯地平等，降压强效平稳，老年高血压首选，与RAS抑制剂黄金联用。
- [[RAS抑制剂]]：ACEI与ARB，心肾微循环保护，降蛋白尿，严禁两类重叠联用。
- [[ARNI]]：沙库巴曲缬沙坦，心衰HFrEF首选及高血压推荐，ACEI转换必须间隔36小时。
- [[β受体阻滞剂]]：美托洛尔缓释片/比索洛尔，心衰新四联与交感亢进首选，慢阻肺安全选药。
- [[阿替普酶与替奈普酶]]：急性脑梗死4.5小时溶栓金标准，溶栓后24小时严禁抗血小板。
- [[第三代EGFR-TKI]]：奥希替尼等，EGFR敏感突变晚期肺癌一线首选及术后辅助3年金标准。
- [[免疫检查点抑制剂]]：PD-1/PD-L1抗体，肝癌、肺癌、结直肠癌跨癌种一线突破。
- [[限制与特殊级抗菌药物]]：呼吸喹诺酮、碳青霉烯类，主治/副主任处方权限与会诊制度。

## 5. 概念与诊疗规范 (Concepts)

- [[高血压分级与靶器官损害评估]]：1/2/3级切点、家庭/动态血压标准、靶器官损害评估。
- [[2型糖尿病诊断切点与控制目标]]：静脉糖切点、HbA1c≥6.5%、个体化分层达标。
- [[CNLC中国肝癌临床分期]]：结合中国国情，Ia~IV期治疗路径决策树。
- [[肺癌TNM分期与驱动基因谱]]：I-IV期分期原则、EGFR/ALK/ROS1等全套靶点指引。
- [[CURB-65肺炎严重度评分]]：5项量化指标判定30天死亡风险与门诊/住院/ICU分流。
- [[GOLD气流受限分级与ABE评估]]：FEV1%pred分级、ABE症状与急性加重风险矩阵。
- [[心力衰竭表型分型与利钠肽诊断阈值]]：HFrEF/HFmrEF/HFpEF/HFimpEF分类、NT-proBNP年龄切点。
- [[结直肠癌高危筛查与直肠MRI评估]]：初筛+FIT+结肠镜路径、CRM切缘与EMVI血管侵犯。
- [[急性缺血性脑卒中静脉溶栓与取栓时间窗]]：4.5h溶栓、6-24h取栓指征、24h抗栓保护期。
- [[抗菌药物三级处方权限与围手术期预防规范]]：三级资质矩阵、I类切口0.5~1h与≤24h限时。

## 6. 综合专题库 (Synthesis)

本模块是 LLM Wiki 的核心价值所在，跨指南解决临床多病共存、药物冲突与复杂决策难题：
- [[心脑血管与代谢性疾病共病管理]]：高血压、糖尿病、冠心病、心衰“四高”联防联控。
- [[慢病多药联合安全与禁忌规避]]：梳理临床六大致命用药红线（36h洗脱、禁联用、造影停药等）。
- [[慢阻肺与心血管共病联合诊治]]：急性呼吸困难鉴别（AECOPD vs 左心衰）、β阻滞剂安全应用。
- [[恶性肿瘤转化治疗与MDT决策路径]]：肝癌、肠癌、肺癌从“不可切除”到“根治性手术”的转化路径。
- [[临床感染经验性治疗降阶梯与抗菌药物合理应用]]：经验覆盖48~72小时评估、靶向降阶梯与短程化。
