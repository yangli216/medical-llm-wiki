# 血脂异常与高脂血症

## 一、 实体定义与流行病学
血脂异常（Dyslipidemia）通常指血清中总胆固醇（TC）、低密度脂蛋白胆固醇（LDL-C）或甘油三酯（TG）水平过高，或高密度脂蛋白胆固醇（HDL-C）水平降低。根据《中国血脂管理指南（2023年）》（[[SRC-CMA-CARD-2023-03]]），我国成人血脂异常总患病率高达 35.6%，其中以轻中度高胆固醇血症及高甘油三酯血症最为多见。

**致病核心**: LDL-C 是导致动脉粥样硬化性心血管疾病（ASCVD）的致病性危险因素。血液中致动脉粥样硬化颗粒长期沉积于血管内膜，导致斑块形成、破裂与急性心肌梗死或缺血性脑卒中。

## 二、 诊断切点与 ASCVD 总体风险分层
常规空腹血脂四项临床参考值：
- **TC**: 理想 < 5.2 mmol/L，边缘升高 5.2～6.2 mmol/L，升高 ≥ 6.2 mmol/L；
- **LDL-C**: 理想 < 3.4 mmol/L，边缘升高 3.4～4.1 mmol/L，升高 ≥ 4.1 mmol/L；
- **TG**: 理想 < 1.7 mmol/L，升高 ≥ 2.3 mmol/L，严重升高 ≥ 5.6 mmol/L（急性胰腺炎高危红线）；
- **HDL-C**: 正常 ≥ 1.0 mmol/L。

根据 ASCVD 总体风险分层设定个体化 LDL-C 达标靶值（详见 [[ASCVD危险分层与LDL-C控制靶标]]）：
1. **超高危人群**（发生过两次严重 ASCVD 事件或一次事件合并多个高危因素）：目标 **LDL-C < 1.4 mmol/L** 且较基线降幅 ≥ 50%；
2. **极高危人群**（既往明确冠心病、心梗、缺血性脑卒中或外周动脉粥样硬化）：目标 **LDL-C < 1.8 mmol/L** 且降幅 ≥ 50%；
3. **高危人群**（糖尿病合并高血压或 LDL-C ≥ 4.9 mmol/L）：目标 **LDL-C < 2.6 mmol/L**；
4. **中低危人群**：目标 **LDL-C < 3.4 mmol/L**。

## 三、 规范化药物干预与联合降脂策略
1. **中等强度他汀为一线基石**: 首选阿托伐他汀钙片（20mg qn）或瑞舒伐他汀钙片（10mg qn）。我国人群对他汀敏感度高，指南推荐中等强度起始，避免初始盲目大剂量强效他汀引起肌毒性与肝损伤；
2. **口服联合降脂（他汀 + 依折麦布）**: 单用他汀 LDL-C 不达标者，联合胆固醇吸收抑制剂依折麦布片（10mg qd），可使 LDL-C 在他汀基础上进一步降低 15%～20%；
3. **严重高 TG 的急性胰腺炎防范**: TG ≥ 5.6 mmol/L 时，首要任务是预防急性坏死性胰腺炎，首选高纯度鱼油制剂（二十碳五烯酸乙酯）或非诺贝特胶囊；
4. **处方安全红线**:
   - 严禁他汀类与吉非罗齐联用（强行阻断他汀葡萄糖醛酸化，引起致死性横纹肌溶解综合征与急性肾衰竭）；
   - 用药期间 ALT/AST 持续升高达正常上限 3 倍以上或 CK 升高达 5 倍以上时，须暂停药物并随访复查。
