# 原发性高血压

## 一、 实体定义与流行病学
原发性高血压（Essential Hypertension）是以体循环动脉血压持续升高为主要特征的慢性心血管综合征，是我国心脑血管疾病（脑卒中、冠心病、心力衰竭）以及慢性肾脏病的首要独立致病因素。根据《中国高血压防治指南（2024年修订版）》（[[SRC-CMA-CARD-2024-01]]），我国成人高血压患病率达27.5%，且呈现年轻化趋势。

---

## 二、 诊断要点与血压分级
在未使用降压药物情况下，非同日3次诊室血压测量：
- **诊断标准**：收缩压（SBP）≥ 140 mmHg 和/或 舒张压（DBP）≥ 90 mmHg。
- **家庭自测血压（HBPM）**：平均血压 ≥ 135/85 mmHg。
- **24小时动态血压（ABPM）**：全天平均 ≥ 130/80 mmHg（白昼 ≥ 135/85，夜间 ≥ 120/70 mmHg）。

详细的血压分级切点（1级、2级、3级及单纯收缩期高血压）与靶器官损害指标详见概念页面：[[高血压分级与靶器官损害评估]]。

## 三、 降压达标靶值
- **一般成年患者（含65~79岁老年人）**：
  - 基础目标：降至 **< 140/90 mmHg**；
  - 强化目标：耐受良好者强烈建议进一步降至 **< 130/80 mmHg**（显著减少心血管复合终点）。
- **合并 [[2型糖尿病]]**：目标推荐 **< 130/80 mmHg**。
- **合并 [[慢性心力衰竭]] 或冠心病**：目标推荐 **< 130/80 mmHg**。
- **≥ 80岁高龄老年人**：首选降至 **< 140/90 mmHg**。

## 四、 药物治疗阶梯与联合策略
一线降压推荐药物包括：
1. **[[钙通道阻滞剂]]（CCB）**：二氢吡啶类，如氨氯地平，降压强效平稳，尤其适合老年高血压及盐敏感性高血压。
2. **[[RAS抑制剂]]（ACEI / ARB）**：具有卓越的靶器官保护（心室重构改善、降低蛋白尿）。
3. **[[ARNI]]（沙库巴曲缬沙坦）**：新指南正式推荐，伴心衰、左室肥厚或肾脏病变者首选。
4. **[[β受体阻滞剂]]**：美托洛尔缓释片、比索洛尔，特别适用于交感神经兴奋、心率增快（>80次/分）或合并心绞痛患者。
5. **噻嗪类利尿剂**：氢氯噻嗪、吲达帕胺。

### 联合用药黄金法则：
- 血压 ≥ 160/100 mmHg 或高危患者，推荐起始即采用两种药物联合（优先推荐单片复方制剂 SPC）。
- 优先组合：`CCB + ACEI/ARB`、`CCB + 噻嗪类利尿剂`、`ACEI/ARB + 噻嗪类利尿剂`、`ARNI + CCB`。
- **严禁联用**：ACEI 与 ARB 不得联合（详见 [[慢病多药联合安全与禁忌规避]]）。
