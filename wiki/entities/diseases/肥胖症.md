# 肥胖症 (Obesity)

## 一、 实体定义与流行病学
肥胖症（Obesity，ICD-10: `E66.9`）是以体内脂肪组织积聚过多或分布异常、体重超过正常参考范围为特征的慢性进行性代谢性疾病。依据国家卫生健康委员会办公厅《肥胖症诊疗指南（2024年版）》（[[SRC-NHC-OBES-2024-01]]）与《成人肥胖食养指南（2024年版）》（[[SRC-NHC-NUT-2024-01]]），我国成年人超重率已达 34.3%，肥胖率达 16.4%，超重与肥胖人群总量超过 50.7%。肥胖症不仅造成机体机械负荷增加，更通过脂肪细胞分泌大量炎性细胞因子（TNF-$\alpha$、IL-6）、游离脂肪酸及异位脂肪沉积，诱发全身慢性微炎症与胰岛素抵抗，是 [[原发性高血压]]、[[2型糖尿病]]、[[动脉粥样硬化性心血管疾病]]、代谢相关脂肪性肝病（MASLD）及多种恶性肿瘤的独立致病诱因。

---

## 二、 诊断标准与量化分级（中国成人）
1. **体质指数（BMI）切点**:
   $$\text{BMI} = \frac{\text{体重}(\text{kg})}{\text{身高}^2(\text{m}^2)}$$
   - **超重 (Overweight)**: $24.0 \le \text{BMI} < 28.0\text{ kg/m}^2$
   - **肥胖症 (Obesity)**: $\text{BMI} \ge 28.0\text{ kg/m}^2$
     - **轻度肥胖（I度）**: $28.0 \le \text{BMI} < 32.5\text{ kg/m}^2$
     - **中度肥胖（II度）**: $32.5 \le \text{BMI} < 37.5\text{ kg/m}^2$
     - **重度肥胖（III度）**: $37.5 \le \text{BMI} < 42.5\text{ kg/m}^2$
     - **极重度肥胖（IV度）**: $\text{BMI} \ge 42.5\text{ kg/m}^2$
2. **中心型肥胖（腹型肥胖）诊断切点**:
   - 成年男性: 腰围 $\ge 90\text{ cm}$
   - 成年女性: 腰围 $\ge 85\text{ cm}$
   - 详细的分级矩阵与体脂比参考见概念页：[[中国成人超重与肥胖症诊断与BMI分级标准]]。

## 三、 并发症筛查与临床风险分层
确诊超重或肥胖症后，需行标准化多系统并发症筛查：
1. **心血管与代谢指标**: 诊室血压、空腹血糖（FPG）、糖化血红蛋白（HbA1c）、空腹胰岛素与C肽（计算 HOMA-IR）、血脂四项（TC、TG、HDL-C、LDL-C）、血清尿酸（SUA）；
2. **肝胆系统**: 肝肾功能、腹部超声（排查脂肪肝、胆囊结石）；
3. **呼吸与骨关节**: 评估睡眠打鼾嗜睡（排查阻塞性睡眠呼吸暂停低通气综合征 OSAS）、负重膝关节活动痛（排查膝骨关节炎）；
4. **排除继发性肥胖**: 筛查甲状腺功能（排查 [[甲状腺功能减退症]]）、血清皮质醇与 ACTH（排查库欣综合征）、性激素全套（女性排查多囊卵巢综合征 PCOS）。

## 四、 规范化干预与阶梯减重策略
1. **全程生活方式基础干预**:
   - 减重目标：3～6 个月内减轻基线体重的 $5\%\sim 10\%$；
   - 饮食能量控制：每日减少能量摄入 $500\sim 1000\text{ kcal}$，维持低脂肪、全谷物膳食，优质蛋白质占比 $\ge 50\%$；
   - 运动处方：每周至少 150～300 分钟中等强度有氧运动，结合每周 2～3 次抗阻运动。
2. **规范化处方药物治疗**:
   - **用药指征**: 严格限制用于生活方式干预 3 个月以上体重未达标，且 $\text{BMI} \ge 28.0\text{ kg/m}^2$ 或 $24.0 \le \text{BMI} < 28.0\text{ kg/m}^2$ 伴代谢并发症者；
   - **首选获批药物**:
     - 脂肪酶抑制剂：**[[奥利司他与抗肥胖药物|奥利司他胶囊]]**（120mg tid 餐时口服）；
     - GLP-1受体激动剂：**[[GLP-1受体激动剂|司美格鲁肽注射液]]**（周制剂，0.25mg qw 起始逐步滴定）；
   - **绝对禁忌拦截**:
     - GLP-1类药物：**甲状腺髓样癌（MTC）或多发性内分泌腺瘤病2型（MEN 2）患者绝对禁用**；
     - 奥利司他：**慢性吸收不良综合征或胆汁淤积症患者绝对禁用**。
3. **减重与代谢外科手术**:
   - $\text{BMI} \ge 37.5\text{ kg/m}^2$ 或 $\text{BMI} \ge 32.5\text{ kg/m}^2$ 伴 2 项及以上代谢并发症者，推荐 MDT 团队评估腹腔镜袖状胃切除术（LSG）或胃旁路术（LRYGB）。
