# 乳腺癌免疫组化分子分型与HER2低表达

## 一、 免疫组化核心生物标志物
根据国家卫生健康委《乳腺癌诊疗指南（2024年版）》（[[SRC-NHC-ONC-2024-03]]），所有浸润性乳腺癌标本均必须在术前活检及术后大标本中规范检测以下四项分子病理指标：
1. **雌激素受体（ER）**：阳性定义为浸润性癌细胞核着色 ≥ 1%；
2. **孕激素受体（PR）**：阳性阈值为 ≥ 1%，高表达临界值通常为 ≥ 20%；
3. **人表皮生长因子受体2（HER2）**：膜着色强度评估及基因原位杂交（FISH/CISH）；
4. **Ki-67 细胞增殖指数**：反映肿瘤增殖活性，通常以 14%~20% 作为高/低增殖界点。

---

## 二、 经典四大分子亚型诊断标准
依据上述四项指标，乳腺癌划分为生物学行为与治疗反应截然不同的四大亚型：

| 分子分型 | ER / PR 状态 | HER2 状态 | Ki-67 状态 | 临床特征与治疗主导 |
| :--- | :--- | :--- | :--- | :--- |
| **Luminal A 型** | ER 强阳性且 PR ≥ 20% | HER2 阴性 (0 或 1+) | 低表达 (< 14%~20%) | 预后最好，内分泌单药极其敏感，免化疗指征多 |
| **Luminal B 型 (HER2-)**| ER 阳性且 (PR < 20% 或 Ki-67 高) | HER2 阴性 | 高表达 (≥ 20%) | 内分泌联合化疗；晚期一线选 [[CDK4与6抑制剂]] |
| **Luminal B 型 (HER2+)**| ER 和/或 PR 阳性 | HER2 阳性 (3+ 或 FISH+) | 任意水平 | 需化疗 + [[曲妥珠单抗与帕妥珠单抗]] 双靶 + 内分泌 |
| **HER2 过表达型** | ER 阴性且 PR 阴性 | HER2 阳性 (3+ 或 FISH+) | 任意水平 | 高度依赖 HER2 通路，首选 HP 双靶新辅助/辅助 |
| **三阴性 (TNBC)** | ER 阴性、PR 阴性 | HER2 阴性 | 任意水平 (通常极高) | 恶性程度高，易内脏转移，化疗联合 [[免疫检查点抑制剂]] |

## 三、 HER2 判读路径与“HER2 低表达（HER2-Low）”新范式

### 1. HER2 标准病理判定流程
- **IHC 0**：无着色，或 ≤10% 的浸润癌细胞呈现微弱不完整膜着色；判定为 **HER2 阴性（Zero）**；
- **IHC 1+**：>10% 的癌细胞呈现微弱且不完整的胞膜着色；判定为 **HER2 低表达（HER2-Low）**；
- **IHC 2+**：>10% 的癌细胞呈弱至中度完整胞膜着色；为**不确定状态，必须加做 ISH/FISH 基因检测**：
  - 若 FISH 阳性（HER2/CEP17比值 ≥2.0 或 拷贝数 ≥6.0），最终判定为 **HER2 阳性**；
  - 若 FISH 阴性，最终判定为 **HER2 低表达（HER2-Low）**；
- **IHC 3+**：>10% 的癌细胞呈强烈完整环状胞膜着色；直接判定为 **HER2 阳性**。

### 2. HER2 低表达（HER2-Low）的革命性意义
- 在既往被判定为 HER2 阴性的乳腺癌患者中，**约有 50%~60% 属于 HER2 低表达**；
- 传统大分子单抗（曲妥珠单抗单药）无法在该人群起效，但具有强大旁观者效应的新一代抗体偶联药物（ADC，如德曲妥珠单抗 T-DXd）能突破受体密度限制，显著延长晚期后线患者的无进展生存与总生存期。
