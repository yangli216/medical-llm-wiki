# 缺铁性贫血实验室诊断与补铁疗效监测

## 一、 临床背景与病理演变分期
根据中华医学会血液学分会红细胞疾病学组《铁缺乏症和缺铁性贫血诊治和预防成人指南（2023年版）》（[[SRC-CMA-HEMA-2023-01]]），铁缺乏是一个缓慢演进的连续病理过程，临床依据体内铁储备、转运铁及红细胞生成情况分为三个渐进阶段：

| 病理生理阶段 | 骨髓/组织储存铁 | 血清铁蛋白 (SF) | 转铁蛋白饱和度 (TSAT) | 血红蛋白 (Hb) | 红细胞形态 (MCV/MCH) | 临床表现 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 储存铁缺乏期 (ID)** | 明显减少或耗竭 | **降低 ($<30\ \mu\text{g/L}$)** | 正常 ($\ge 20\%$) | 正常 | 正常 | 无贫血症状 |
| **2. 缺铁性红细胞生成期 (IDE)** | 完全耗尽 | **显著降低 ($<15\ \mu\text{g/L}$)** | **降低 ($<20\%$)** | 正常或正常下限 | 正常或轻微下降 | 乏力、组织微缺铁 |
| **3. 缺铁性贫血期 (IDA)** | 完全耗尽 | **极低 ($<12\sim15\ \mu\text{g/L}$)** | **显著降低 ($<15\%$ 或 $<20\%$)** | **明显低于正常下限** | **小细胞低色素 ($<80 / <27$)** | 典型贫血与组织缺铁体征 |

## 二、 核心实验室生化指标判读与阈值

### 1. 血常规红细胞参数（见 [[全血细胞分析(血常规)]]）
- **贫血切点（海平面成人）**: 成年男性 $\text{Hb} < 120$ g/L，非孕成年女性 $\text{Hb} < 110$ g/L，孕妇 $\text{Hb} < 100$ g/L；
- **微细胞低色素表征**: $\text{MCV} < 80$ fL，$\text{MCH} < 27$ pg，$\text{MCHC} < 320$ g/L；
- **红细胞分布宽度 (RDW-CV)**: 显著增高（$> 15\%$），提示显著异质性红细胞大小不均（与轻型地中海贫血 RDW 正常或轻度升高形成鲜明鉴别）。

### 2. 铁代谢指标矩阵
- **血清铁蛋白（Serum Ferritin, SF）——确诊铁缺乏基石指标**:
  - **无炎症基础患者**: $\text{SF} < 30\ \mu\text{g/L}$（或部分实验室采用 $< 20\ \mu\text{g/L}$）高度敏感且特异，直接提示储存铁耗竭；
  - **合并急慢性感染、炎症、自身免疫病、恶性肿瘤、慢性肾病或心衰时（结合 [[C反应蛋白测定]]）**: 铁蛋白作为急性期反应蛋白常代偿性升高。此时 $\text{SF} < 100\ \mu\text{g/L}$ 仍高度提示合并铁缺乏，必须结合 $\text{TSAT} < 20\%$ 作出综合诊断。
- **转铁蛋白饱和度（Transferrin Saturation, TSAT）**:
  - 计算公式：$\text{TSAT} = (\text{血清铁} / \text{总铁结合力}) \times 100\%$；
  - $\text{TSAT} < 20\%$ 为转运铁不足的明确病理切点。
- **血清铁 (SI) 与总铁结合力 (TIBC)**:
  - $\text{SI} < 8.95\ \mu\text{mol/L}$（$50\ \mu\text{g/dL}$）；
  - $\text{TIBC} > 64.4\ \mu\text{mol/L}$（$360\ \mu\text{g/dL}$），未饱和铁结合力明显升高。
- **可溶性转铁蛋白受体（sTfR）**:
  - 当骨髓红系前体细胞缺铁时受体高表达并脱落进入血液，血清 sTfR 浓度显著升高；
  - 优势：不受急慢性炎症影响，是鉴别缺铁性贫血与慢性病性贫血（ACD）的关键分子标记。

## 三、 补铁治疗动态反应与疗效监测时间轴

规范补铁治疗后，体内生化与血液学指标呈现高度规律性的时间演变阶梯：

```
补铁起始 ───(5～10天)───> 网织红细胞达峰(Ret peak) ───(2周)───> Hb开始显著上升 ───(4～8周)───> Hb恢复正常 ───(巩固3～6个月)───> 补足骨髓储存铁(SF>50μg/L)
```

1. **第 5～10 天 —— 骨髓造血代偿响应期**:
   - 外周血网织红细胞（Reticulocyte, Ret）百分比及绝对计数明显升高，于第 5～10 天达到高峰（可达 $4\%\sim10\%$）；
   - **临床意义**: 是评估口服或静脉铁剂是否吸收并发挥生物学效应的最早指征。若网织红细胞无反应，须立即排查：①服药依从性不良；②存在吸收干扰（如与茶、牛奶、钙片同服）；③伴随胃大部切除或肠道病变；④诊断有误（如地中海贫血或 MDS）。
2. **第 2 周 —— 血红蛋白开始回升期**:
   - 外周血血红蛋白（Hb）开始升高，红细胞形态逐步改善，乏力气促等临床缺氧症状明显缓解。
3. **第 4～8 周 —— 贫血纠正达标期**:
   - 外周血 Hb 恢复至正常生理参考范围（女性 $\ge 110$ g/L，男性 $\ge 120$ g/L），MCV 与 MCH 参数恢复正常。
4. **第 3～6 个月 —— 巩固补充储存铁期（最核心临床红线）**:
   - **停药判定标准**: **绝对不能因血红蛋白恢复正常即停止服药！**；
   - 此时机体储存铁仍处于极低或耗竭状态，停药后极易复发；
   - 必须按维持量继续服药 **3～6 个月**，复查血清铁蛋白 **$\text{SF} > 50\ \mu\text{g/L}$** 且 TSAT 稳定于正常范围，方可安全减量或停药。

## 四、 静脉铁剂总缺铁量计算（Ganzoni 公式）

针对口服不耐受、吸收障碍或重症患者需要静脉补铁时，推荐使用国际公认的 Ganzoni 公式计算累积总需铁量：

### 1. 计算公式
$$\text{总缺铁量 (mg)} = \text{体重 (kg)} \times (\text{目标Hb} - \text{实际Hb}) \times 2.4 + \text{储存铁量 (mg)}$$

### 2. 参数取值规范
- **体重 (kg)**: 患者实际体重；过度肥胖患者宜取理想体重；
- **目标血红蛋白 (目标Hb, g/dL)**:
  - 成人一般设定为 $15.0\text{ g/dL}$（即 $150\text{ g/L}$）；
- **实际血红蛋白 (实际Hb, g/dL)**:
  - 患者当前实测 Hb，注意单位换算（$1\text{ g/L} = 0.1\text{ g/dL}$）；
- **转换系数 2.4**:
  - 由 $0.0034$（每克 Hb 含铁量约 3.4 mg）$\times 0.07$（血液容积约占体重 7%）$\times 10,000$（单位统一系数）推导得出；
- **储存铁量 (mg)**:
  - 体重 $\ge 35$ kg 的成年人，体内储存铁量统一按 **$500\text{ mg}$** 计算；
  - 体重 $< 35$ kg 者按 $15\text{ mg/kg}$ 计算。

### 3. 临床转化换算示例
若 60 kg 女性患者，实测 Hb 70 g/L（7.0 g/dL）：
$$\text{总缺铁量} = 60 \times (15.0 - 7.0) \times 2.4 + 500 = 60 \times 8.0 \times 2.4 + 500 = 1152 + 500 = 1652\text{ mg}$$
若选用蔗糖铁注射液（每支含元素铁 100 mg），则全疗程共需输注约 16～17 支，分次缓慢滴注完成。
