# GRADE 循证证据分级与临床推荐强度规范 (Medical LLM Wiki 标准)

## 一、 体系定义与临床定位
GRADE（Grading of Recommendations Assessment, Development and Evaluation）是世界卫生组织（WHO）、国际临床指南制定组织（如 UpToDate、CMA 中华医学会）普遍采纳的**证据质量评估与推荐强度分级金标准**。

在 **Medical LLM Wiki** 与 CDSS 智能引擎中，GRADE 体系是区分“**法定/强制红线阻断（强推荐）**”与“**个体化经验选择（弱推荐）**”的核心依据，赋予医疗大模型明确的临床决策确定性边界。

---

## 二、 证据质量分级 (Quality of Evidence)

| 证据等级 | 代码 | 定义与置信度特征 | 典型研究依据来源 |
| :---: | :---: | :--- | :--- |
| **高 (High)** | **A** | 我们非常确信真实效应值接近估计值。进一步研究极不可能改变该评估的置信度。 | 设计严谨的大样本多中心随机对照试验（RCT）或其系统评价/Meta分析 |
| **中 (Moderate)** | **B** | 对真实效应值的确信程度中等。进一步研究可能对评估结果产生重要影响。 | 存在降级因素的 RCT（偏倚风险、不一致性），或极高质量的大型前瞻性队列研究 |
| **低 (Low)** | **C** | 对真实效应值的确信程度有限。进一步研究极有可能改变该评估结果。 | 观察性研究（队列研究、病例对照研究）或存在严重缺陷的 RCT |
| **极低 (Very Low)** | **D** | 我们对效应值的估计几乎没有把握。 | 专家共识意见、个案报道、病例系列或存在严重偏倚的间接证据 |

## 三、 临床推荐强度分级 (Strength of Recommendation)

| 推荐强度 | 代码 | 临床决策含义 | 医生与患者视角 | CDSS 引擎系统行为 |
| :---: | :---: | :--- | :--- | :--- |
| **强推荐 (Strong)** | **1** | **利明确大于弊**（或弊明确大于利）。绝大多数患者应接受该干预措施。 | 几乎所有知情患者都会选择该方案；医生应无保留推荐。 | **RED 红色强阻断 / 核心必选用药**（不可随意豁免，偏离需强制记录理由） |
| **弱推荐 (Weak)** | **2** | **利弊平衡接近**，或证据质量较低。不同患者可能做出不同合理选择。 | 患者的选择受其价值观和偏好影响；医生需进行医患共同决策。 | **YELLOW 黄色预警 / 备选平替建议**（柔性提醒，支持医生个体化权衡） |

## 四、 复合分级矩阵与 CDSS 执行标准

```
┌─────────────────────────────────────────────────────────────┐
│ 1A 级: 强推荐，高质量证据 (临床铁律/法定禁忌/一线基石方案)    │ -> 严禁触碰，触发强制阻断拦截
│ 1B 级: 强推荐，中等质量证据 (多数国家指南推荐方案)          │ -> 强力提示，首选方案
│ 1C 级: 强推荐，低质量证据 (公认临床常识/不可逆危害保护)      │ -> 强力警示，防范致死致残风险
├─────────────────────────────────────────────────────────────┤
│ 2A 级: 弱推荐，高质量证据 (利弊相当/依从性差异方案)          │ -> 备选提示，个体化选择
│ 2B 级: 弱推荐，中等质量证据 (二线平替药物/辅助用药)          │ -> 柔性提示，提供平替对照
│ 2C 级: 弱推荐，低质量证据 (经验性探索/专家推荐)              │ -> 参考建议，慎重权衡
└─────────────────────────────────────────────────────────────┘
```

## 五、 与知识库核心病种协议的映射范例
1. **1A 级典型**：
   - 2型糖尿病无禁忌患者首选 [[盐酸二甲双胍片]] 一线降糖；
   - eGFR < 30 mL/min 时绝对禁用二甲双胍（防范乳酸酸中毒）；
   - 严禁双重 RAS 轴阻断（ACEI + ARB / ARNI 联用）；
   - 头孢菌素应用期间及停药 7 天内严禁饮酒或服用含乙醇制剂（防范致死性双硫仑样反应）。
2. **1B 级典型**：
   - 心力衰竭射血分数降低（HFrEF）患者启动“新四联”（ARNI + β受体阻滞剂 + MRA + SGLT2i）；
   - 高血压合并冠心病首选 CCB 或 β受体阻滞剂联合降压。
3. **2B 级典型**：
   - 痛风急性期不能耐受 NSAIDs 或秋水仙碱者，短期选用小剂量口服糖皮质激素；
   - 慢性便秘一线容积性泻药效果欠佳时，联合短期促动力药。
