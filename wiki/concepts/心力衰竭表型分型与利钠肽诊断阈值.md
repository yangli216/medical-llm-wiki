# 心力衰竭表型分型与利钠肽诊断阈值

## 一、 心衰四大临床表型分类
根据《中国心力衰竭诊断和治疗指南（2024）》（[[SRC-CMA-CARD-2024-02]]），基于左心室射血分数（LVEF）划分四种临床表型：

| 心衰表型分类 | 英文简称 | LVEF 诊断界值 | 核心病理机制与指南首选治疗方案 |
| :--- | :--- | :--- | :--- |
| **射血分数降低心衰** | **HFrEF** | **≤ 40%** | 心肌收缩力严重减退、进行性心室扩大。“新四联”基石（[[ARNI]] + [[β受体阻滞剂]] + MRA + [[SGLT2抑制剂]]） |
| **射血分数轻度降低心衰** | **HFmrEF** | **41% ～ 49%** | 具有部分收缩与舒张双重缺陷。[[SGLT2抑制剂]] 优先，可借鉴 HFrEF 新四联用药 |
| **射血分数保留心衰** | **HFpEF** | **≥ 50%** | 心室肌顺应性下降、左室舒张充盈受限。**[[SGLT2抑制剂]] 成为首个 I 类推荐改善预后药物**；联合利尿剂 |
| **射血分数改善心衰** | **HFimpEF** | **随访时 > 40%** | **基线 LVEF ≤ 40%，经抗心衰规范治疗后复查 LVEF > 40% 且绝对值较基线提升 ≥ 10%**。严格要求**终身维持治疗，严禁擅自停药** |

---

## 二、 生物标志物诊断与排除界值（BNP 与 NT-proBNP）

### 1. 慢性心力衰竭排除切点（高阴性预测价值）：
- **BNP < 35 pg/mL** 或 **NT-proBNP < 125 pg/mL**；
- 若低于此阈值，基本可排除心力衰竭诊断。

### 2. 急性心力衰竭年龄分层诊断阈值：
由于 NT-proBNP 水平受年龄和肾功能明显影响，临床诊断急性心衰必须严格按照年龄分层切点判定：

| 年龄 / 临床状态分层 | NT-proBNP 诊断临界值 | BNP 诊断临界值 |
| :--- | :--- | :--- |
| **< 50 岁** | **≥ 450 pg/mL** | ≥ 100 pg/mL |
| **50 ～ 75 岁** | **≥ 900 pg/mL** | ≥ 100 pg/mL |
| **> 75 岁（高龄老年）** | **≥ 1800 pg/mL** | ≥ 100 pg/mL |
| **伴肾功能不全（eGFR < 60）** | **≥ 1200 pg/mL** | ≥ 200 pg/mL |
