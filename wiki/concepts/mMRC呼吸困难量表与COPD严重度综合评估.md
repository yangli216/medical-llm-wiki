# mMRC 呼吸困难量表与 COPD 综合评估规范

## 一、 临床背景与核心价值
慢性阻塞性肺疾病（COPD）是呼吸系统最常见的慢性疾病。根据《中国慢性阻塞性肺疾病诊治指南（2021/2024）》与全球 GOLD 指南，单纯依靠肺功能 FEV1% 无法完整反映患者的实际生活质量与急性加重风险。

**改良英国医学研究学会呼吸困难量表 (mMRC)** 凭借其客观、易测、无需昂贵仪器的特点，成为门诊评估呼吸困难程度与指导**GOLD 阶梯吸入用药分组（A/B/E 组）**的法定基石。

---

## 二、 mMRC 呼吸困难 5 级量化标准

| 级别 (Grade) | 患者主诉与呼吸困难严重度特征 | 临床意义 |
| :---: | :--- | :--- |
| **0 级** | 仅在**剧烈运动或费力活动**时才感到呼吸困难。 | 正常或轻微受限 |
| **1 级** | 在平地**快步行走或微上坡**时感到呼吸急促、气短。 | 轻度呼吸困难 |
| **2 级** | 在平地行走时，**比同龄人走得慢**；或者以正常速度平地行走时**需要停下来休息**。 | **中度呼吸困难 (关键临床分割线)** |
| **3 级** | 在平地行走**约 100 米或数分钟后**，就需要停下来喘气。 | 重度呼吸困难 |
| **4 级** | 因为严重气促而**足不出户**，或在**穿脱衣服时**即出现明显呼吸困难。 | 极重度呼吸困难 |

## 三、 结合急性加重史的 GOLD ABE 综合分组与用药决策

```
                   急性加重史 (近1年)
                  ┌───────────────────────┐
                  │ ≥ 2 次中度加重        │
                  │ 或 ≥ 1 次导致住院加重  │
                  └───────────┬───────────┘
                              │
                              ▼
                      【 E 组 (Exacerbation) 】
                      首选: 双支扩剂 LABA + LAMA
                      若血嗜酸粒细胞 (EOS) ≥ 300 / 伴哮喘病史:
                      升级为三联疗法 (ICS + LABA + LAMA)
                              ▲
                              │ 0 次或 1 次且未住院
                  ┌───────────┴───────────┐
                  │                       │
          mMRC 0～1 级            mMRC ≥ 2 级 (症状重)
                  │                       │
                  ▼                       ▼
            【 A 组 】              【 B 组 】
      首选: 单一长效支扩剂    首选: 双联长效支扩剂
      (LAMA 或 LABA 吸入)     (LABA + LAMA 联合吸入制剂)
```

## 四、 CDSS 智能用药决策联动逻辑
1. **阻断低效单药**：当患者 mMRC ≥ 2 级（B 组），若医生仅开具单联沙丁胺醇气雾剂或单一茶碱缓释片，CDSS 提示升级为 LABA+LAMA（如噻托溴铵/奥达特罗、乌美溴铵/维兰特罗）；
2. **严防 ICS 泛滥**：当患者处于 A 组或 B 组且血 EOS < 100 / 无哮喘病史，严禁常规起始吸入糖皮质激素（ICS），防范诱发继发性肺炎风险。
