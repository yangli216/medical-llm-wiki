# 急性缺血性脑卒中静脉溶栓与取栓时间窗

## 一、 静脉溶栓标准时间窗与药物规范（发病 ≤ 4.5 小时）
根据《中国急性缺血性脑卒中诊治指南（2023）》（[[SRC-CMA-NEUR-2023-01]]），静脉溶栓必须遵循“时间就是大脑”原则，DNT（入院至用药时间）≤ 60 分钟。

### 1. 适用药物与给药细则：
- **[[阿替普酶与替奈普酶]]**（rt-PA）：
  - 剂量 0.9 mg/kg（最大 90 mg），10% 1分钟推注，90% 维持 60 分钟滴注（I类推荐，A级证据）。
- **替奈普酶**（TNK）：
  - 剂量 0.25 mg/kg（最大 25 mg），5～10 秒单次静脉推注（I类推荐，B级证据）。

### 2. 绝对禁忌证快速排查清单：
- 头颅平扫 CT 证实脑出血或蛛网膜下腔出血；
- 近 3 个月有严重颅脑外伤或脑梗死；
- 恶性颅内肿瘤或颅内动静脉畸形；
- 活动性内脏大出血；
- 血压极高（经积极平稳降压后仍 SBP ≥ 185 mmHg 或 DBP ≥ 110 mmHg）；
- 血液凝血异常（血小板 < 100 × 10⁹/L，INR > 1.7，48小时内使用 NOAC）。

## 二、 血管内治疗（机械取栓）时间窗决策树

```mermaid
flowchart TD
    AIS[急性缺血性脑卒中发病] --> Window{发病时间窗判断}
    
    Window -- 发病 ≤ 4.5小时 --> IVT[无禁忌证立即启动静脉溶栓\n阿替普酶或替奈普酶]
    IVT --> Bridge{CTA/MRA 确认前循环大血管闭塞?}
    Bridge -- 是 (ICA / MCA M1闭塞) --> EVT6[立即桥接血管内机械取栓\n无需等待溶栓起效观察]
    Bridge -- 否 --> Ward[普通卒中单元监护]
    
    Window -- 4.5小时 < 发病 ≤ 6小时 --> LVO{大血管闭塞且 ASPECTS≥6?}
    LVO -- 是 --> EVT6
    LVO -- 否 --> Antiplatelet[抗血小板与内科综合治疗]
    
    Window -- 6小时 < 发病 ≤ 24小时\n(含醒后卒中) --> MultiModal[急诊多模影像评估: CTP / MRP]
    MultiModal --> Mismatch{符合组织窗错配?\n梗死核心小且缺血半暗带显著}
    Mismatch -- 是 (DAWN / DEFUSE 3 标准) --> EVT24[延迟时间窗机械取栓: 强烈推荐]
    Mismatch -- 否 (大面积梗死核心) --> Medical[保守内科治疗，严防脑疝与再灌注出血]
```

---

## 三、 溶栓后 24 小时抗栓铁律
- **溶栓后 24 小时内绝对推迟抗血小板与抗凝治疗**；
- 溶栓满 24 小时后，**必须复查头颅平扫 CT**，确认无任何出血转化后方可启动抗血小板治疗（阿司匹林或氯吡格雷）。
