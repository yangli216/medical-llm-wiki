# BPH 下尿路症状 IPSS 量表与药物联合规范

## 一、 国际前列腺症状评分 (IPSS) 与分级
IPSS 是国际公认量化评估良性前列腺增生（BPH）患者下尿路症状（LUTS）严重程度的标准工具：

| 评估项目 (近1个月内) | 评分标准 (0~5分) |
| :--- | :--- |
| 1. 排尿不尽感 (是否感觉未排尽) | 从不(0分) ~ 几乎每次(5分) |
| 2. 两次排尿间隔 $<2$ 小时 (尿频) | 从不(0分) ~ 几乎每次(5分) |
| 3. 排尿中断 (排尿中间断数次) | 从不(0分) ~ 几乎每次(5分) |
| 4. 憋尿困难 (难以忍受尿意) | 从不(0分) ~ 几乎每次(5分) |
| 5. 尿线变细无力 | 从不(0分) ~ 几乎每次(5分) |
| 6. 排尿踌躇 (需用力或等待方能排出) | 从不(0分) ~ 几乎每次(5分) |
| 7. 夜尿次数 (入睡至早起起夜次数) | 无(0分)、1次(1分)、2次(2分)、3次(3分)、4次(4分)、$\ge 5$次(5分) |

### 严重程度分级与干预策略
- **轻度症状 (0~7 分)**: 警惕等待观察，生活方式干预（限制晚间咖啡酒精、睡前 2 小时限制饮水）；
- **中度症状 (8~19 分)**: 推荐药物治疗（单药或联合）；
- **重度症状 (20~35 分)**: 积极药物联合治疗，评估残余尿；严重者转诊评估经尿道前列腺电切术（TURP）。
- **生活质量指数 (QOL，0~6分)**: 0分高兴 ~ 6分极痛苦，辅助综合决断。

## 二、 药物联合应用规范（坦索罗辛 + 非那雄胺）
1. **联合指征**:
   - 伴中重度下尿路症状（IPSS $\ge 8$ 分）；
   - 前列腺体积明显增大（超声前列腺体积 $>30\text{ml}$，或直肠指检明显增大）；
   - 伴血清 PSA 升高（但在正常参考区间 $1.5\sim 4.0\text{ ng/ml}$）。
2. **两药互补优势**:
   - **坦索罗辛 0.2mg qn**: 48 小时内快速松弛膀胱颈平滑肌，直接通畅尿流；
   - **非那雄胺 5mg qd**: 连续口服 3~6 个月抑制双氢睾酮，前列腺体积缩小 20%~30%，使急性尿潴留风险降低 57%，手术切除率下降 55%；
   - 联合用药兼顾“即刻见效”与“远期延缓疾病进展”。

## 三、 CDSS 处方安全禁忌与警示
1. **绝对禁止盲目处方抗胆碱能药物**:
   - 凡 BPH 患者伴严重排尿困难或残余尿量 $>100\text{ml}$，**严禁使用阿托品、消旋山莨菪碱（654-2）、东莨菪碱**！抗胆碱药麻痹膀胱逼尿肌，可直接诱发急性尿潴留（AUR）；
2. **体位性低血压防跌倒提示**:
   - 坦索罗辛建议每晚临睡前服用，对高龄且合并多种降压药者，提示夜间起床排尿时慢坐起 1 分钟再站立，防体位性晕厥与跌倒。
