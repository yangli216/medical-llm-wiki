# 临床感染经验性治疗降阶梯与抗菌药物合理应用

## 一、 临床痛点：经验用药广谱覆盖与细菌耐药危机的博弈
在临床感染性疾病（如中重度 [[社区获得性肺炎]]、腹腔感染、脓毒血症等）救治中，由于微生物病原学培养与药敏试验需要 48~72 小时出结果，医师必须在第一时间给予“经验性抗感染治疗”。然而，如果盲目、长期维持广谱高档抗菌药物，将导致多重耐药菌（MDRO，如耐碳青霉烯类肠杆菌 CRE、MRSA）暴发及难辨艰难梭菌相关性腹泻。

国家卫生健康委《抗菌药物临床应用指导原则》（[[SRC-NHC-PHAR-2015-01]]）与中华医学会《成人CAP指南》（[[SRC-CMA-RESP-2016-02]]）明确制定了 **“先送检、后用药，经验广谱、及时降阶梯（De-escalation）”** 的标准策略。

---

## 二、 降阶梯治疗（De-escalation）四步标准化实施路径

```mermaid
flowchart TD
    Patient[患者确诊细菌感染 / 急重症入院] --> Step1[第一步: 规范留取合格标本\n血培养/痰液/尿液/引流液涂片送检]
    Step1 --> Step2[第二步: 尽早经验性治疗\n结合 CURB-65 / 感染部位 / 耐药流行病学选药]
    Step2 --> Step3[第三步: 48~72 小时黄金临床评估\n体温 / 炎症指标 (CRP/PCT) / 微生物培养与药敏出炉]
    Step3 --> Decision{病情改善且药敏明确?}
    Decision -- 是 --> Step4[第四步: 坚决实施降阶梯!\n高档改中低档/广谱改窄谱/双联改单药/静脉转口服]
    Decision -- 否 --> Recheck[排查耐药菌/非感染病因/引流不畅/再次送检]
```

### 1. 第一步：先送检、后用药（法定红线）
- 在使用第一剂抗菌药物之前，必须采集合格的标本。
- 重症患者在寒战或体温高峰期采集至少 2 套（需氧瓶+厌氧瓶）外周血培养。

### 2. 第二步：初始经验性重锤猛击
- 根据感染部位、CURB-65 严重度分层（详见 [[CURB-65肺炎严重度评分]]）及本院耐药监测谱，选用覆盖最可能病原体的足量抗菌药物（如 CAP 住院重症选用 β-内酰胺类联合呼吸喹诺酮或阿奇霉素）。

### 3. 第三步：48~72 小时窗口期动态评估
- 观察患者热程、外周血象、C反应蛋白（CRP）、降钙素原（PCT）及器官功能反应。

### 4. 第四步：精准降阶梯与短程化
- **降谱/降级**：一旦药敏证实为敏感菌（如产ESBLs阴性大肠埃希菌或敏感肺炎链球菌），立即将碳青霉烯类或限制级头孢吡肟降级为非限制/限制级的一代、二代头孢或氨苄西林舒巴坦。
- **序贯口服**：体温正常 48~72 小时且胃肠吸收良好，立即由静脉输注改为口服生物利用度高的制剂。
- **疗程终结**：常规感染疗程严格控制在 5~7 天，杜绝无指征预防性长期用药。

---

## 三、 结合处方权限的质控把关
- 在实施抗感染治疗全流程中，严格执行 [[限制与特殊级抗菌药物]] 权限规定：
  - 特殊使用级抗生素（碳青霉烯、万古霉素等）不仅开具受限，且在 72 小时内必须由感染专科药师跟进药敏报告并实施降阶梯督导，未及时降阶梯者系统预警。
