# 《抗菌药物临床应用指导原则》研读

- **文献标识**: `SRC-NHC-PHAR-2015-01`
- **制定机构**: [[国家卫生健康委员会]] / 国家中医药管理局 / 中央军委后勤保障部卫生局
- **刊发刊物**: 国卫办医发官方文件 / 国家法定临床管理规范
- **原始源文件**: `raw/docs/SRC-NHC-PHAR-2015-01.md`
- **适用病种**: 各类细菌与真菌感染性疾病、围手术期预防用药

---

## 二、 核心更新与管理准则
1. **三大基石原则**：临床用药必须遵循“安全、有效、经济”。病毒感染严禁使用抗菌药物。
2. **“先送检、后用药”法定化**：启动用药前必须规范采集微生物标本送病原学培养及药敏，作为医疗质量考核核心指标。
3. **三级处方权限严格管控**：
   - 非限制使用级：初级医师均可处方；
   - 限制使用级：主治医师及以上方可处方；
   - 特殊使用级：仅限高级职称（副主任医师及以上）处方，且**必须经感染科专科医师或临床药师会诊签字**方可执行，门诊全面禁用。
4. **围手术期预防用药严格限缩**：清洁（I类）切口原则上不预防用药；确需预防者，必须在**切开前0.5～1小时**内给药，术后用药时限严格**控制在24小时内**，杜绝滥用第三代头孢菌素。
