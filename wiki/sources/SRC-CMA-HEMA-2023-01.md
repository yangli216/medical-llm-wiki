# 《铁缺乏症和缺铁性贫血诊治和预防成人指南（2023年版）》研读导读

## 一、 文献元数据与权威背景
- **文献标识代码**: `SRC-CMA-HEMA-2023-01`
- **颁布与编撰组织**: 中华医学会血液学分会红细胞疾病学组
- **出版载体**: 《中华血液学杂志》2023年第44卷第1期，第1–7页
- **DOI**: `10.3760/cma.j.cn121090-20221102-00517`
- **权威背景**:
  - 本指南是我国红细胞疾病学界针对成人铁缺乏症（ID）与缺铁性贫血（IDA）制定的权威临床专科实践指南；
  - 铁缺乏症是全球也是我国患病率最高的微量元素营养缺乏症和单病种贫血原因，严重损害心肺耐力、免疫功能、认知水平及孕产妇围产期安全；
  - 指南系统梳理了从储存铁减少（ID）到缺铁性红细胞生成（IDE），直至典型小细胞低色素缺铁性贫血（IDA）的病理生理进展链条；
  - 指南不仅明确了血清铁蛋白（SF）与转铁蛋白饱和度（TSAT）的量化切点，更确立了“病因筛查前置”与“补足储存铁（巩固治疗 3～6 个月）”的两大临床安全底线。
- **规制范围**: 成人及妊娠期缺铁性贫血诊断标准、铁代谢全套生物学标志物评估、胃肠道与妇科潜在恶性病变排查路径、口服铁剂规范与吸收干扰规避、静脉铁剂指征与 Ganzoni 补铁公式。

## 二、 核心临床决策要点

1. **缺铁的三阶段病理演变模型**:
   - **ID（储存铁缺乏期）**: 骨髓及网状内皮系统储存铁耗尽，血清铁蛋白 SF 降低，Hb 正常，无贫血临床表征；
   - **IDE（缺铁性红细胞生成期）**: 储存铁耗竭累及红系前体细胞铁利用，转铁蛋白饱和度 TSAT $< 20\%$，sTfR 升高，Hb 处于正常下限；
   - **IDA（缺铁性贫血期）**: 红细胞血红蛋白合成明显不足，出现小细胞低色素性贫血（MCV $< 80$ fL, MCH $< 27$ pg），Hb 显著低于标准。

2. **确立无炎症 SF $< 30\ \mu\text{g/L}$ 与有炎症 SF $< 100\ \mu\text{g/L}$ 核心指标**:
   - 血清铁蛋白是反映机体总铁储存的最敏感非侵入性生化指标；
   - 在合并感染、肿瘤、肝病或结缔组织病等急性期反应时，SF 会反应性升高。此时不能单纯以普通正常参考下限排除缺铁，指南指出若合并炎症且 SF $< 100\ \mu\text{g/L}$ 时仍应高度疑诊缺铁，必须配合 TSAT $< 20\%$ 综合判定。

3. **病因筛查第一原则（警惕胃肠道恶性肿瘤与隐性失血）**:
   - 贫血是疾病的表现，查明缺铁原发病因是根治的先决条件；
   - 成年男性和绝经后女性确诊缺铁性贫血，必须进行消化道内镜（胃镜、结肠镜）及便潜血检查，排查消化道溃疡、息肉及早期胃癌、结直肠癌；
   - 育龄期女性必须系统排查月经过多、子宫肌瘤及腺肌症。

4. **口服补铁首选与巩固期治疗红线（3～6 个月）**:
   - 首选口服补铁（每日元素铁 $100\sim200$ mg，如琥珀酸亚铁、多糖铁复合物），配合维生素 C 协同还原；
   - 纠正临床误区：严禁在血红蛋白恢复正常时立即停药！必须继续维持用药 **3～6 个月**（或直至血清铁蛋白 SF $> 50\ \mu\text{g/L}$），以彻底补足机体 $500\sim1000$ mg 的储备铁，否则复发率极高。

5. **静脉铁剂适应证与 Ganzoni 总缺铁量精准测算**:
   - 针对口服严重不耐受、吸收障碍（胃切除术后、活动性 IBD）、重度急需补铁者，推荐羧基麦芽糖铁或蔗糖铁；
   - 严格采用 Ganzoni 公式计算患者实际总铁缺乏量，避免凭经验估算盲目给药导致铁超载风险。
