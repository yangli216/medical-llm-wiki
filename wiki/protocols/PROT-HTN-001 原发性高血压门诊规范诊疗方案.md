# 原发性高血压门诊规范诊疗方案

## 1. 临床方案概述 (Protocol Summary)
本方案依据 [[SRC-CMA-CARD-2024-01|中国高血压防治指南（2024年修订版）]] 与 [[SRC-CMA-CARD-2019-03|国家基层高血压防治管理指南]] 制定，专门赋能门诊医生站 AI 治疗方案推荐与 CDSS 临床安全核查。适用于门诊诊断为 [[原发性高血压]] 的成人患者，规范降压药物选择、靶器官损害评估筛查及生活方式综合干预。

- **核心目标**: 血压达标（一般患者目标 < 130/80 mmHg；老年及虚弱患者分步达标 < 140/90 mmHg），预防靶器官损害与心脑血管事件。
- **治疗原则**: 小剂量起始、优先长效制剂、联合用药（2级及以上高血压或高危患者优先两药起始联合）、个体化治疗。

## 2. 门诊病历范文模板 (Note Template Content)
*本模板供医生站 AI 一键生成规范门诊病历，严禁使用待填写占位符，严禁伪造具体生命体征数值。*

### 主诉 (chiefComplaint)
间断头晕、头胀伴后枕部发紧 2 周，测血压升高 3 天。

### 现病史 (presentIllness)
患者诉 2 周前劳累后出现间断头晕、头部胀痛感，以后枕部发紧为主，活动或紧张时明显，休息后可稍有缓解。3 天前在社区卫生站测量血压偏高，今为求系统诊治来门诊。病程中无视物旋转、黑曚及听力下降，无胸痛、胸闷及放射性肩背痛，无气促、心悸及下肢水肿，无肢体无力、麻木及言语不清，无恶心、呕吐及意识障碍。起病以来精神状态良好，食欲可，夜间睡眠欠佳，大小便正常，近期体重无明显改变。

### 既往史 (medicalHistory)
既往体健，否认冠心病、糖尿病、慢性肾脏病及脑血管病史；否认肝炎、结核等传染病史及接触史；否认药物及食物过敏史；否认重大手术、外伤及输血史；预防接种史随社会进行。

### 体格检查 (physicalExam)
神志清楚，精神可，言语流利，自主体位，查体配合。双侧瞳孔等大等圆，对光反射灵敏。颈软，双侧颈动脉未闻及血管杂音，颈静脉无充盈。双肺呼吸音清，未闻及干湿性啰音。心界不大，心率整齐，心音有力，各瓣膜听诊区未闻及病理性杂音及额外心音。腹部平软，无压痛及反跳痛，肝脾肋下未触及，双侧肾区无叩击痛，腹部未闻及血管杂音。双下肢无水肿，四肢肌力5级、肌张力正常，双侧病理征未引出。

### 健康宣教 (healthEducation)
1. 低盐低脂平衡膳食：每日食盐摄入量严格控制在 5g 以下，减少高钠调味品及腌制食品，增加富含钾、镁的新鲜蔬菜与水果摄入；
2. 戒烟限酒与体重控制：严格戒烟并远离二手烟，限制饮酒或戒酒；控制体重指数（BMI < 24 kg/m²），腹围男性 < 90 cm、女性 < 85 cm；
3. 规律作息与有氧运动：每周进行 150 分钟以上中等强度有氧运动（如快走、太极拳），避免突发剧烈运动与过度负重，保证充足睡眠，保持心情舒畅；
4. 规范家庭血压监测：早晚固定时间测量双上臂坐位血压，记录血压日记并在就诊时提供给医生。

### 复诊与随访计划 (followUp)
用药后 2 至 4 周首次门诊复诊，评估降压疗效、药物耐受性及电解质、肾功能；若出现剧烈头痛、喷射性呕吐、视物模糊、胸痛胸闷、心悸气促、突发肢体偏瘫或麻木等危险警示征象，须立即急诊就医。

## 4. CDSS 用药前置拦截与警戒规则 (Clinical Decision Rules)

1. **绝对禁忌拦截 (Rule-HTN-001)**:
   - 若患者处方包含 ACEI（如依那普利、卡托普利）或 ARB（如氯沙坦、缬沙坦）或 [[ARNI]]：
     - 若患者为**妊娠期**女性，系统触发**红色强行阻断**（致畸与胚胎毒性风险）。
     - 若患者合并**高钾血症（血钾 > 5.5 mmol/L）**或**双侧肾动脉狭窄**，系统触发**红色强行阻断**。
2. **严禁双重 RAS 阻断 (Rule-HTN-002)**:
   - 严禁 ACEI 与 ARB、或 ARB 与 ARNI 双重联用，触发**红色阻断**（显著增加急性肾损伤与高钾血症风险，无额外临床获益）。
3. **处方瀑布与水肿防误判 (Rule-HTN-003)**:
   - 若服用二氢吡啶类 [[钙通道阻滞剂]]（如氨氯地平、硝苯地平）出现下肢凹陷性水肿，属于毛细血管前动脉扩张所致毛细血管压力增高，并非体液潴留。系统发出**黄色警示**：避免盲目叠加排钾利尿剂（处方瀑布）；建议联合使用 [[RAS抑制剂]] 扩张毛细血管后微静脉以减轻水肿。
4. **初始降压联用阈值警戒 (Rule-HTN-004)**:
   - 普通轻度高血压初始治疗不得默认联用 3 种及以上降压药物；不得将保钾利尿剂（螺内酯）作为普通高血压的一线起始药物。
