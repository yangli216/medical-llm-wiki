# 儿童支气管哮喘诊断与防治指南（2020年版）

- **文献ID**: SRC-CMA-PED-2020-01
- **发布机构**: 中华医学会儿科学分会呼吸学组 / 中华儿科杂志编辑委员会
- **发布年份**: 2020
- **刊物**: 《中华儿科杂志》2020年第58卷第9期

## 核心推荐条款
1. **诊断要点与可逆性气流受限证实 (I 类推荐, A 级证据)**:
   - 反复发作的喘息、咳嗽、气促、胸闷，夜间及清晨发作或加剧，多数患儿可自行缓解或经平喘治疗缓解；
   - 肺功能证实可逆性气流受限：支气管舒张试验阳性（FEV1 改善 $\ge 12\%$）或 PEF 昼夜变异率 $>13\%$；对于 $<6$ 岁儿童，依据临床表现与哮喘预测指数（mAPI）进行临床诊断。
2. **急性发作期快速解痉治疗 (I 类推荐, A 级证据)**:
   - 一线首选吸入短效 $\beta_2$ 受体激动剂（SABA，如硫酸特布他林或沙丁胺醇雾化吸入溶液），联合吸入性糖皮质激素（ICS，布地奈德混悬液 1mg 雾化吸入），每 20 分钟可重复吸入共 3 次；中重度发作联合异丙托溴铵。
3. **长期维持治疗阶梯管理与降级原则 (I 类推荐, A 级证据)**:
   - 吸入糖皮质激素（ICS）为儿童哮喘长期控制的一线基石首选（如布地奈德吸入悬液每日 0.5~1.0mg 或丙酸氟替卡松气雾剂）；
   - $\ge 6$ 岁儿童中重度哮喘可升级为 ICS + LABA（福莫特罗）联合治疗；
   - 白三烯受体拮抗剂（LTRA，孟鲁司特钠咀嚼片）适用于轻度持续哮喘或阿司匹林哮喘/过敏性鼻炎共病患儿；
   - 达到完全控制满 3 个月后方可考虑单级降量降阶梯，严禁擅自骤停药物导致急性致命性哮喘反弹。
4. **给药装置与儿童依从性管理 (I 类推荐, A 级证据)**:
   - $<6$ 岁首选压力定量气雾剂（pMDI）连接带面罩的储雾罐（Spacer）或压缩泵雾化吸入；$\ge 6$ 岁可用含嘴式储雾罐或干粉吸入剂（DPI）；每次吸入后必须漱口并洗脸（防止局部鹅口疮与声音嘶哑）。
