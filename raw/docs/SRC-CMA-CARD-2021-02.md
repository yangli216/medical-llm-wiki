# 《心房颤动：目前的认识和治疗建议（2021）》规范全文要点

## 一、 基本信息与学术权威
- **发布机构**：中华医学会心电生理和起搏分会 / 中国医师协会心律学专业委员会
- **发表刊物**：《中华心律失常学杂志》2021年第25卷
- **核心定位**：中国心房颤动综合管理、脑卒中一级与二级预防、抗凝与抗心律失常药物规范应用的国家级临床共识指南。

## 二、 核心诊断与危险评估标准
1. **心房颤动确诊依据**：
   - 标准12导联心电图记录到房颤（无明显P波，代之以不规则颤动波f波，RR间期绝对不整齐，持续时间≥30秒）；
   - 或单导联心电图记录到房颤发作持续≥30秒。
2. **缺血性脑卒中风险评估 (CHA2DS2-VASc 评分)**：
   - 充血性心衰 (C: 1分)、高血压 (H: 1分)、年龄≥75岁 (A2: 2分)、糖尿病 (D: 1分)、既往卒中/TIA/血栓栓塞 (S2: 2分)、血管疾病 (V: 1分)、年龄65~74岁 (A: 1分)、女性性别 (Sc: 1分)；
   - **抗凝指征**：男性评分≥2分、女性评分≥3分，强烈推荐长期口服抗凝治疗（I类推荐，A级证据）；男性1分、女性2分者权衡获益与出血风险推荐口服抗凝（IIa类推荐）。
3. **出血风险评估 (HAS-BLED 评分)**：
   - 评分≥3分提示出血高危，但不是抗凝禁忌证，而是警示应筛查纠正可逆出血危险因素，并加强门诊随访。

## 三、 抗凝与心室率/节律控制药物策略
1. **抗凝药物选择**：
   - 非瓣膜性房颤患者首选新型直接口服抗凝药 (DOACs，如利伐沙班、达比加群酯)（I类推荐，优于华法林）；
   - 机械人工心脏瓣膜置换术后或中重度二尖瓣狭窄房颤患者，绝对禁用 DOACs，必须使用华法林（维持 INR 2.0~3.0）。
2. **心室率控制目标**：
   - 宽松心室率控制策略：静息心率 < 110 次/分；若仍有症状或合并左室功能受损，严格控制至静息心率 < 80 次/分、中度运动时心率 < 110 次/分；
   - 一线药物：心选择性 β受体阻滞剂（琥珀酸美托洛尔缓释片、富马酸比索洛尔）或非二氢吡啶类钙通道阻滞剂（地尔硫䓬、维拉帕米，禁用于心衰HFrEF）。
