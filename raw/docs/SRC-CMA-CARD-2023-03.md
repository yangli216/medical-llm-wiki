# 中国血脂管理指南（2023年）

- **文献标识**: SRC-CMA-CARD-2023-03
- **制定机构**: 国家心血管病专家委员会 / 中华医学会心血管病学分会 / 中华医学会糖尿病学分会 / 中华医学会内分泌学分会 / 中华医学会检验医学分会
- **刊发刊物**: 《中华心血管病杂志》2023年第51卷第3期
- **发布年份**: 2023年

---

## 一、 指南概述与主要修订背景

动脉粥样硬化性心血管疾病（ASCVD）是我国城乡居民首位死亡原因。低密度脂蛋白胆固醇（LDL-C）是ASCVD的致病性危险因素。自《中国成人血脂异常防治指南（2016年修订版）》发布以来，降脂药物研发（特别是PCSK9抑制剂与siRNA药物）和多项大规模循证临床研究取得了突破性进展。

《中国血脂管理指南（2023年）》由多学科专家联合制定，核心宗旨是基于中国人群心血管疾病风险流行病学数据，推行全人群、全生命周期的血脂分层管理，制定更为科学严格的LDL-C目标靶值，并确立联合降脂的新策略。

---

## 二、 血脂检测项目与临床界值

### 1. 常规血脂四项临床参考标准（mmol/L）
| 指标 | 理想水平 | 合适水平 | 边缘升高 | 升高 | 降低 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **总胆固醇 (TC)** | - | <5.2 (200 mg/dL) | 5.2~6.1 | ≥6.2 (240 mg/dL) | - |
| **低密度脂蛋白胆固醇 (LDL-C)** | <2.6 | <3.4 (130 mg/dL) | 3.4~4.0 | ≥4.1 (160 mg/dL) | - |
| **甘油三酯 (TG)** | - | <1.7 (150 mg/dL) | 1.7~2.2 | ≥2.3 (200 mg/dL) | - |
| **高密度脂蛋白胆固醇 (HDL-C)** | - | ≥1.0 (40 mg/dL) | - | - | <1.0 |

*注：非-HDL-C（总胆固醇减去高密度脂蛋白胆固醇）作为高甘油三酯血症患者的次要干预靶点，其目标值为对应LDL-C目标值 + 0.8 mmol/L（30 mg/dL）。*

## 三、 ASCVD 总体心血管危险分层体系

指南明确指出，降脂治疗的强度与达标值必须依据个体的 **ASCVD 总体心血管危险分层**：

### 1. 超高危人群（Extreme High Risk）
- 发生过 **≥2次严重ASCVD事件**（如近期急性冠脉综合征ACS、既往心肌梗死病史、缺血性卒中、有症状的外周动脉疾病）；
- 或发生 **1次严重ASCVD事件合并 ≥2个高风险因素**（糖尿病、年龄≥65岁、吸烟、早发冠心病家族史、既往行冠状动脉旁路移植术CABG或PCI、顽固性高血压、eGFR 15~59 mL/min/1.73m²、LDL-C未达标且≥2.6 mmol/L）。

### 2. 极高危人群（Very High Risk）
- 已确诊为 ASCVD（冠心病、缺血性卒中、短暂性脑缺血发作TIA、外周外周动脉硬化闭塞等），但不满足超高危标准者。

### 3. 高危人群（High Risk）
- 原发性严重高胆固醇血症（LDL-C ≥4.9 mmol/L 或 TC ≥7.2 mmol/L）；
- 40岁及以上糖尿病患者（LDL-C 1.8~4.9 mmol/L）；
- 经中国心血管病总体风险评估模型预测10年ASCVD发病危险 ≥10% 者。

### 4. 中危与低危人群
- 根据高血压、吸烟、低HDL-C、年龄等危险因素组合评估10年发病危险 <10% 的个体。

## 四、 LDL-C 与非-HDL-C 分层达标靶值（核心指标）

指南强调“**低一些，好得多**（Lower is Better）”以及“**达标率与降幅双考核**”原则：

| 危险分层 | LDL-C 目标值 | 非-HDL-C 目标值 | 补充达标要求 |
| :--- | :--- | :--- | :--- |
| **超高危** | **<1.4 mmol/L** (55 mg/dL) | <2.2 mmol/L | 且较基线降幅 ≥50% |
| **极高危** | **<1.8 mmol/L** (70 mg/dL) | <2.6 mmol/L | 且较基线降幅 ≥50% |
| **高危** | **<2.6 mmol/L** (100 mg/dL) | <3.4 mmol/L | 较基线降幅 ≥50% |
| **中危 / 低危** | **<3.4 mmol/L** (130 mg/dL) | <4.1 mmol/L | 基础生活方式干预为主 |

*若超高危患者在2年内发生2次血管事件（尽管已使用最大耐受剂量他汀治疗），可考虑更严格的控制目标：LDL-C <1.0 mmol/L (40 mg/dL)。*

## 五、 降脂药物治疗路径与联合方案

### 1. 药物基石：中等强度他汀类药物
- **中国人群药效特征**：中国人群对他汀类药物的代谢敏感性高，耐受性较欧美人群低，大剂量强效他汀（如阿托伐他汀80mg、瑞舒伐他汀40mg）引起肝酶异常和肌病的风险明显增加。
- **推荐策略**：首选**常用剂量/中等强度他汀**（如阿托伐他汀 20 mg、瑞舒伐他汀 10 mg、匹伐他汀 2 mg）。

### 2. 联合治疗阶梯：口服双联与注射三联
- **第一阶梯（他汀 + 胆固醇吸收抑制剂）**：中等强度他汀治疗4~6周后，LDL-C仍未达标者，联合使用**依折麦布**（10 mg/日）或海博麦布。联合降脂可使LDL-C额外降低15%~20%。
- **第二阶梯（他汀 + 依折麦布 + PCSK9抑制剂）**：
  - 超高危或极高危患者，若双联口服治疗后LDL-C仍未达标，尽早联合使用 **PCSK9 单克隆抗体**（依洛尤单抗 140 mg q2w 或 阿利西尤单抗 75/150 mg q2w）；
  - 或长效 siRNA 药物 **英克司兰 (Inclisiran)**（皮下注射，每年仅需2次），强效降低 LDL-C 达 50%~60%。
- **极危重症初始联合**：对于基线 LDL-C 极高、预计单药绝不可能达标的超高危患者（如急性心肌梗死合并糖尿病），可直接在入院时启动他汀与 PCSK9 抑制剂的早期联合降脂。

## 六、 药物安全性监测与不良反应处理

1. **肝转氨酶（ALT/AST）**：
   - 用药前检测基线值；用药后4~8周复查；
   - 若ALT/AST升高 <3倍正常上限（ULN），可继续服药并密切观察；
   - 若ALT/AST持续 ≥3倍 ULN，应减量或停药，待恢复正常后更换他汀品种或降低剂量并联合依折麦布。
2. **肌酸激酶（CK）与肌病**：
   - 用药期间如出现不能解释的肌肉疼痛、乏力，应及时检测CK；
   - 若 CK >5倍 ULN，应立即停药，并密切监测肾功能（预防横纹肌溶解）。
3. **他汀不耐受管理**：
   - 可采取隔日服药、换用不同代谢途径他汀（如经CYP2C9代谢的瑞舒伐他汀或经葡萄糖醛酸化的匹伐他汀）、或直接采用依折麦布联合PCSK9抑制剂方案。
