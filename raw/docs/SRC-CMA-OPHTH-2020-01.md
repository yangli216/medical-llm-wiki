# 中国干眼专家共识（2020年）

- **文献ID**: SRC-CMA-OPHTH-2020-01
- **发布机构**: 中华医学会眼科学分会角膜病学组
- **发布年份**: 2020
- **刊物**: 《中华眼科杂志》2020年

## 核心推荐条款
1. **干眼定义与分型诊断 (I 类推荐, A 级证据)**:
   - 干眼是多因素引起的慢性眼表疾病，以泪膜稳态破坏伴眼部干涩、异物感、灼热感为特征；泪膜破裂时间(FBUT) $\le 5$s 或 Schirmer I 试验 $\le 5$mm/5min 伴眼表荧光素染色阳性支持诊断；临床分为水液缺乏型、脂质异常型、黏蛋白异常型、泪动力学异常型及混合型（临床最常见）。
2. **人工泪液基础润滑与无防腐剂原则 (I 类推荐, A 级证据)**:
   - 各型干眼基础治疗一线首选人工泪液（如 0.1%~0.3% 玻璃酸钠滴眼液、聚乙烯醇滴眼液）；每天点眼次数 $\ge 4$ 次或中重度干眼建议优先选择单支独立包装、不含防腐剂的剂型，避免防腐剂毒性损害角膜上皮。
3. **眼表抗炎与合理用药红线 (I 类推荐, B 级证据)**:
   - 伴眼表显著炎症者联合低浓度糖皮质激素（短期 ≤2 周）或 0.05% 环孢素滴眼液；严禁长期滥用含缩血管剂（如盐酸萘甲唑啉）或广谱抗生素的复合眼药水，防药物性角膜炎与结膜充血反跳。
