# 《中华人民共和国药典临床用药须知与国家基本药物处方集》

- 发布机构：国家药典委员会 / 国家卫生健康委合理用药专家委员会
- 权威出版：中国医药科技出版社（2024年版）
- 适用范围：临床各级医师、临床药师、药学服务机构、基层医疗卫生机构

## 一、 药典临床用药须知与基本药物处方集定位
《中华人民共和国药典临床用药须知》与《国家基本药物处方集》是国家药品法典的重要配套技术规范，是国家保障基本用药、指导临床合理用药的法定依据与权威指南：
1. **用药规范**：确立临床各科常见疾病的药物遴选原则、首选及一线用药方案；
2. **剂量与滴定规范**：详尽规定各品种的常规给药剂量、维持剂量、安全日极量、疗程以及器官功能不全时的减量方案；
3. **不良反应与监护**：系统梳理高警示不良反应、监测指标（如转氨酶、肌酸激酶、血肌酐、血钾、INR、QTc间期等）与处置方案；
4. **配伍与联用禁忌**：详细解析物理化学配伍禁忌、药动学与药效学相互作用，指导多药联用时的错峰给药与方案规避。

## 二、 肾功能分级与剂量调整核心标准
针对肾脏清除途径药物，严格依据慢性肾脏病（CKD）分期及 eGFR 阈值实施精准分级调整：
- **正常或轻度受损**（eGFR ≥ 60 mL/min/1.73m²）：通常按常规推荐剂量给药；
- **中度受损**（eGFR 30~59 mL/min/1.73m²）：
  - 二甲双胍：eGFR 45~59 建议减半（日极量 ≤ 1000mg），eGFR 30~44 需严格密切监测并减半，部分指南警示；
  - 呋喃妥因：eGFR < 45（或 < 30）疗效下降且蓄积毒性增加；
  - 别嘌醇：按 eGFR 梯级减量（eGFR 30~50 最大 100~200mg/d）；
- **重度受损与肾衰竭**（eGFR < 30 mL/min/1.73m²）：
  - 绝对禁用：二甲双胍（乳酸酸中毒风险）、阿仑膦酸钠（eGFR < 35 禁用）、SGLT2抑制剂控糖适应症（起始受限）、部分磺脲类、呋喃妥因等；
  - 调整方案：优先选择肝胆代谢清除或无肾毒性替代药物（如利格列汀无需根据肾功调量）。

## 三、 特殊人群安全用药原则
1. **妊娠与哺乳期**：
   - 严格避免致畸风险药品（FDA 妊娠分级 D/X 类或 NMPA 明确妊娠禁忌），如普利类/沙坦类降压药（可致胎儿肾发育不全、羊水过少）、他汀类降脂药、氟康唑（口服大剂量致畸）、华法林（致畸综合征）等；
2. **老年患者（≥ 65 岁）**：
   - 贯彻“小剂量起始、缓慢加量”原则；
   - 严格防范抗胆碱能负荷过高引发认知障碍、尿潴留及便秘；
   - 严防长效苯二氮䓬类药物（如地西泮）导致的步态不稳、跌倒骨折风险；
3. **儿童患者**：
   - 严禁病毒感染发热使用阿司匹林（防 Reye 综合征）；
   - 18 岁以下禁用喹诺酮类抗菌药物（软骨发育风险）；
   - 8 岁以下儿童禁用四环素类药物（四环素牙、骨骼发育受限）。
