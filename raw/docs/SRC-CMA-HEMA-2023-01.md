## 一、疾病定义与病理生理演变阶段

铁缺乏是全球及中国最常见的营养缺乏和贫血病因。体内铁代谢失衡经历三个连续的渐进发展阶段：

1. **储存铁耗竭期 (Iron Depletion, ID)**:
   - 体内储存铁（骨髓幼红细胞含铁血黄素、肝脾网状内皮系统铁蛋白）耗尽；
   - 实验室特征：血清铁蛋白（Serum Ferritin, SF）降低；
   - 血清铁（SI）、总铁结合力（TIBC）、转铁蛋白饱和度（TSAT）、血红蛋白（Hb）均维持正常，患者无贫血临床症状。

2. **缺铁性红细胞生成期 (Iron Deficient Erythropoiesis, IDE)**:
   - 储存铁已耗竭，红细胞摄入铁不足以支持血红素合成；
   - 实验室特征：SF 显著降低，转铁蛋白饱和度 TSAT $< 20\%$，血清可溶性转铁蛋白受体（sTfR）浓度升高，游离原卟啉（FEP）升高；
   - 骨髓铁粒幼红细胞 $< 15\%$；血红蛋白（Hb）仍保持正常或轻度下限边缘，无典型小细胞低色素。

3. **缺铁性贫血期 (Iron Deficiency Anemia, IDA)**:
   - 缺铁进一步加重，红细胞生成障碍导致明显的微细胞低色素性贫血；
   - 实验室特征：不仅存在体内缺铁指标异常，且外周血红蛋白明显低于正常参考下限（男性 $< 120$ g/L，非孕女性 $< 110$ g/L，孕妇 $< 100$ g/L），伴 MCV $< 80$ fL，MCH $< 27$ pg，MCHC $< 320$ g/L。

## 二、诊断标准与实验室指标阈值

### 1. 贫血定义（我国海平面地区成人标准）
- **成年男性**: $\text{Hb} < 120$ g/L；
- **成年非孕女性**: $\text{Hb} < 110$ g/L；
- **妊娠期妇女**: $\text{Hb} < 100$ g/L（孕中晚期血液稀释标准）。

### 2. 外周血涂片与红细胞参数
- **平均红细胞体积 (MCV)**: $< 80$ fL（微细胞）；
- **平均红细胞血红蛋白量 (MCH)**: $< 27$ pg（低色素）；
- **平均红细胞血红蛋白浓度 (MCHC)**: $< 320$ g/L；
- **红细胞体积分布宽度 (RDW)**: RDW-CV 常 $> 15\%$（红细胞形态大小不均，有助于与地中海贫血鉴别，后者通常 RDW 正常或轻度升高）。

### 3. 铁代谢核心确诊指标
- **血清铁蛋白 (SF)**:
  - **无炎症/感染状态下**: $\text{SF} < 30\ \mu\text{g/L}$（或部分实验室采用 $< 20\ \mu\text{g/L}$），为最具特异性和敏感性的非侵入性确诊指标。
  - **合并急慢性炎症、肿瘤、感染、肝病、心衰或慢性肾病时**: 铁蛋白属于急性期反应蛋白，血清水平假性代偿升高。此时若 $\text{SF} < 100\ \mu\text{g/L}$，仍应高度怀疑合并缺铁，需结合转铁蛋白饱和度综合评判。
- **转铁蛋白饱和度 (TSAT)**: $\text{TSAT} < 20\%$（$\text{TSAT} = \text{血清铁} / \text{总铁结合力} \times 100\%$）。
- **血清铁 (SI) 与总铁结合力 (TIBC)**:
  - $\text{SI} < 8.95\ \mu\text{mol/L}$（$50\ \mu\text{g/dL}$）；
  - $\text{TIBC} > 64.4\ \mu\text{mol/L}$（$360\ \mu\text{g/dL}$）；未饱和铁结合力（UIBC）升高。
- **可溶性转铁蛋白受体 (sTfR)**:
  - 浓度明显升高（不受急性期炎症影响，是鉴别慢性病性贫血 ACD 的关键分子标志物）。
- **骨髓铁染色（金标准，非首选常规）**:
  - 骨髓小粒细胞外铁消失（0分），细胞内铁（铁粒幼红细胞比例）$< 15\%$。通常在病因不明确、治疗反应不佳或需排除骨髓增生异常综合征（MDS）时采用。

## 三、病因筛查路径与临床红线原则

> **临床核心铁律**: 缺铁性贫血本质上是基础疾病的临床表现，而非终极诊断。“见贫血补铁”而不查明病因属于严重医疗缺陷。

### 1. 需铁量增加与摄入不足
- 青少年生长发育突增期、育龄期女性妊娠与哺乳；
- 挑食、长期严格素食（植物性非血红素铁生物利用度仅 $1\%\sim5\%$，远低于肉类血红素铁 $15\%\sim35\%$）。

### 2. 吸收障碍
- 胃大部切除术或胃肠吻合术后（胃酸缺乏导致铁无法解离还原）；
- 幽门螺杆菌（Hp）感染性胃炎、自身免疫性萎缩性胃炎；
- 乳糜泻、克罗恩病、小肠吸收不良综合征；
- 长期服用强效质子泵抑制剂（PPI）或 H2 受体拮抗剂降低胃内酸度。

### 3. 慢性失血（最主要、危害最大的病因）
- **消化道失血**:
  - 消化性溃疡、糜烂性胃炎；
  - **消化系统肿瘤（胃癌、结直肠癌、结肠息肉、小肠间质瘤）**：成年男性与绝经后女性必须全面警惕！
  - 肠道寄生虫（如钩虫病）、血管发育不良、痔疮出血、长期服用阿司匹林或 NSAIDs 药物。
- **妇科失血**:
  - 育龄期女性月经过多（月经量 $> 80$ ml）、子宫腺肌症、子宫平滑肌瘤、功能失调性子宫出血（功血）、宫内节育器刺激。
- **其他隐匿失血**:
  - 泌尿系肿瘤或结石、反复咯血、阵发性睡眠性血红蛋白尿（PNH）含铁血黄素尿丢失。

## 四、阶梯治疗与用药规范

### 1. 病因治疗（第一优先级）
- 止血、手术切除胃肠道良恶性肿瘤、息肉内镜下电切除、规范根除幽门螺杆菌、调整妇科异常子宫出血。

### 2. 口服补铁（一线首选途径）
- **治疗原则**: 能口服者首选口服，安全、有效、经济。
- **常用推荐制剂与元素铁含量**:
  - **琥珀酸亚铁片（速力菲）**: $0.1$ g/片，每片含元素铁约 $35$ mg。推荐成人用量：$0.1\sim0.2$ g，每日 $2\sim3$ 次，餐后服用。
  - **多糖铁复合物胶囊（力蜚乐）**: $0.15$ g/粒，每粒含元素铁约 $150$ mg。推荐成人用量：$0.15$ g（1粒），每日 $1\sim2$ 次。该药为有机螯合铁，胃肠道局部刺激反应（恶心、便秘、腹痛）明显低于传统无机铁盐。
  - **富马酸亚铁片**: $0.2$ g/片，含元素铁约 $66$ mg。
  - **硫酸亚铁缓释片**: $0.45$ g/片，含元素铁约 $90$ mg。
- **推荐每日元素铁剂量**: 成人轻中度 IDA 推荐每日口服元素铁 $100\sim200$ mg，分次服用或单次顿服。
- **促吸收协同药**:
  - 维生素 C 片：每次 $100\sim200$ mg，随铁剂同时口服。抗坏血酸的还原性可保护亚铁离子不被氧化，并促进三价铁还原为可吸收的二价铁离子。
- **药物相互作用与饮食禁忌**:
  - 严禁与浓茶、咖啡、牛奶同服（茶多酚、鞣酸、高钙与铁离子结合产生难溶沉淀，阻碍吸收）；
  - 避免与含铝、镁、钙的抗酸药物（铝碳酸镁、碳酸钙、硫糖铝）或 H2RA/PPI 同时服用，服药时间应错开至少 2 小时；
  - 避免与四环素类、氟喹诺酮类抗生素同服，两者形成难吸收的金属螯合物，双向降低生物利用度。

### 3. 疗效评估时间表与巩固期治疗（核心红线）
- **第 5～10 天**: 外周血网织红细胞（Reticulocyte, Ret）计数升高并达到高峰（表明骨髓红系造血启动代偿反应）；
- **第 2 周**: 外周血血红蛋白（Hb）开始升高；
- **第 4～8 周**: 血红蛋白恢复至正常范围；
- **巩固补铁疗程（切勿过早停药）**:
  - 临床常见误区：Hb 一恢复正常患者便自行停药，导致短期内贫血频繁复发；
  - **指南红线**: Hb 恢复正常后，必须继续按常规维持剂量口服补铁治疗 **3～6 个月**（或直至血清铁蛋白 $\text{SF} > 50\ \mu\text{g/L}$），以彻底补足体内耗竭的储存铁（约 $500\sim1000$ mg）。

### 4. 静脉铁剂补充（二线与特定指征）
- **适用人群与适应证**:
  1. 口服铁剂严重消化道反应不能耐受；
  2. 消化道吸收障碍（活动性炎症性肠病 IBD、全胃/胃大部切除术后、萎缩性胃炎）；
  3. 消化道持续活动性出血（失血速度快于口服补充速度）；
  4. 妊娠中晚期重度贫血急需短期纠正；
  5. 慢性肾功能衰竭血液透析合并缺铁、心力衰竭伴功能性铁缺乏；
  6. 择期大手术前需要短期内快速提升血红蛋白。
- **常用静脉铁剂**:
  - **羧基麦芽糖铁注射液 (Ferric Carboxymaltose)**: 结构稳定，可大剂量快速滴注（单次最高可达 $1000$ mg 元素铁，输注时间 $15$ 分钟）。
  - **蔗糖铁注射液 (Iron Sucrose)**: 常用剂量每次 $100\sim200$ mg 元素铁，稀释于生理盐水中静脉缓慢滴注，每周 $2\sim3$ 次。
- **总缺铁量计算公式（Ganzoni 公式）**:
  $$\text{总补铁量 (mg)} = \text{体重 (kg)} \times (\text{目标Hb} - \text{实际Hb}) \times 2.4 + \text{储存铁量 (mg)}$$
  *(说明：Hb 单位为 g/dL；若以 g/L 计算，系数为 $0.24$；体重 $\ge 35$ kg 时成人储存铁通常设为 $500$ mg；目标 Hb 设定为 $150$ g/L)*。
- **静脉铁剂不良反应与防范**:
  - 必须警惕极少数患者出现的过敏反应与呼吸困难，输注前备好急救药品，输注前 15 分钟密切监测生命体征。

## 五、特殊人群缺铁防治要点

1. **妊娠期妇女**:
   - 妊娠中晚期对铁需求激增，常规产检应在孕早期及孕 28 周筛查 Hb 与 SF；
   - 对无贫血的孕妇，孕中期起可预防性补充元素铁 $30\sim60$ mg/d；确诊 IDA 孕妇推荐每日补充元素铁 $100\sim200$ mg。
2. **老年人**:
   - 老年缺铁性贫血常掩盖恶性肿瘤病灶，必须排查便隐血并追踪内镜；
   - 警惕并发心肌缺血或认知功能减退。
