# 基层医疗卫生机构急危重症早期识别与双向转诊规范

- **文献标识**: SRC-NHC-PRIM-2022-01
- **制定机构**: 中华人民共和国国家卫生健康委员会基层卫生健康司 / 中华医学会全科医学分会
- **刊发发布**: 国家卫生健康委官方发文 / 《中华全科医师杂志》
- **发布年份**: 2022年

---

## 一、 规范出台背景与全科“守门人”双向转诊职责

在我国“基层首诊、双向转诊、急慢分治、上下联动”的分级诊疗格局中，社区卫生服务中心、乡镇卫生院及社区卫生服务站等基层医疗卫生机构是覆盖人口最广的第一道防线。

全科医生的职责绝非仅限于慢性病开药，更具有**“在常见、模糊或未分化的主诉中，极早期敏锐识别潜在致命急危重症，实施规范就地紧急初期生命支持，并安全无缝转诊至上级医院”**的关键安全网功能。

---

## 二、 国家早期预警评分（NEWS）与生命体征红线

规范全面推行采用**国家早期预警评分系统（National Early Warning Score, NEWS）**对基层就诊患者进行客观生理参数风险分层：

### 1. NEWS 六项核心生理参数评分表：
| 生理指标 | 3 分 | 2 分 | 1 分 | 0 分 | 1 分 | 2 分 | 3 分 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **呼吸频率 (次/分)** | ≤ 8 | - | 9 ~ 11 | **12 ~ 20** | - | 21 ~ 24 | ≥ 25 |
| **脉搏血氧饱和度 (SpO2, %)** | ≤ 91 | 92 ~ 93 | 94 ~ 95 | **≥ 96** | - | - | - |
| **是否吸氧 (Air or Oxygen)** | - | 吸氧 (Yes) | - | **空气 (No)** | - | - | - |
| **收缩压 (SBP, mmHg)** | ≤ 90 | 91 ~ 100 | 101 ~ 110 | **111 ~ 219** | - | - | ≥ 220 |
| **心率 (次/分)** | ≤ 40 | - | 41 ~ 50 | **51 ~ 90** | 91 ~ 110 | 111 ~ 130 | ≥ 131 |
| **意识状态 (AVPU)** | - | - | - | **清醒 (Alert)** | - | - | **对声音反应 (V) / 对疼痛反应 (P) / 无反应 (U)** |
| **体温 (℃)** | ≤ 35.0 | - | 35.1 ~ 36.0 | **36.1 ~ 38.0** | 38.1 ~ 39.0 | ≥ 39.1 | - |

### 2. 基层临床响应行动矩阵：
- **低风险（总分 0 ~ 4 分）**：基层全科医生可在门诊完成诊疗与观察，制定常规随访；
- **中度风险（总分 5 ~ 6 分 或 单项指标达 3 分）**：提示病情潜在不稳定，必须立即由资深全科医生复核，复查生命体征，准备吸氧与建立静脉通道，评估上转；
- **极高危风险（总分 ≥ 7 分）**：**病情危重濒死！必须立即启动基层急救预案，就地抢救同时立即拨打 120 呼叫急救转运车转送三级医院急诊科**。

## 三、 基层四大急危重症就地即刻处置与上转通道

基层医生面对急症严禁“不加处置、盲目让患者自行前往大医院”，必须遵循“**先稳定生命体征、就地初始救护、专车转运交接**”原则：

### 1. 急性缺血性胸痛（疑似 STEMI / ACS）：
- **就地处置**：立即绝对卧床休息、指脉氧吸氧；10分钟内完成首份心电图；
- **抗栓预给药**：若无活动性出血禁忌，立即给予**阿司匹林 300 mg 嚼服 + 替格瑞洛 180 mg（或氯吡格雷 300mg）**；
- **转诊通道**：直拨 120，将心电图通过医联体微信群提前上传至上级胸痛中心，实现“绕行急诊直接进导管室”。

### 2. 突发急性脑卒中（FAST 原则识别）：
- **识别线索**：突发面瘫歪嘴（Face）、单侧手臂下垂无力（Arm）、言语含糊不清（Speech）；
- **全科排雷必查项**：**必须现场立即测定微量末梢血糖！**（极其重要！低血糖昏迷极易完美模拟脑卒中偏瘫，若为低血糖立即静推高糖可避免脑坏死与误诊）；
- **就地处置**：保持呼吸道通畅、头偏向一侧防误吸、**严禁盲目静脉大剂量滴注甘露醇或降压药**；在 4.5 小时静脉溶栓时间窗内紧急转运至卒中中心。

### 3. 重症急性过敏性休克（Anaphylaxis）：
- **临床征象**：用药或进食后突发喉头水肿（喘鸣、失音窒息）、大汗淋漓、全身荨麻疹、血压断崖式骤降（收缩压 <90 mmHg）；
- **第一救命黄金神药**：**立即大腿前外侧肌内注射肾上腺素 0.3 ~ 0.5 mg (1:1000)**！严禁因寻找血管建立静脉通路而延误肌注，每隔 5~15 分钟可重复肌注；同时平卧下肢抬高、吸氧并快速补液。

### 4. 急性左心衰竭 / 肺水肿：
- **就地处置**：端坐位、双腿下垂以减少回心血量；高流量吸氧；口服或静推呋塞米 20~40 mg；血压升高者舌下含服硝酸甘油；立即呼叫 120。

## 四、 规范双向转诊与社区康复闭环机制

1. **下转条件（急慢分治回基层）**：
   - 急性冠脉综合征介入术后病情平稳出院；
   - 脑卒中溶栓/取栓术后进入生命体征平稳康复期；
   - 慢阻肺/心衰急性加重经三级医院纠正后出院。
2. **基层承接与管理闭环**：
   - 社区家庭医生团队在接到下转出院信息后 **3 天内**完成首次家庭访视或门诊对接；
   - 规范执行二级预防长处方、开展家庭病床与运动康复指导。
