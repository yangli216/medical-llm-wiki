# 《妊娠期高血压疾病诊治指南（2020）》核心条款归档

## 一、 文献基本信息
- 制定机构：中华医学会妇产科学分会妊娠期高血压疾病学组
- 出处：《中华妇产科杂志》2020年第55卷第4期

## 二、 核心诊断与分型标准
1. **妊娠期高血压**: 妊娠20周后首次出现收缩压≥140 mmHg和（或）舒张压≥90 mmHg，于产后12周内恢复正常；尿蛋白阴性。
2. **子痫前期**: 妊娠20周后出现收缩压≥140 mmHg和（或）舒张压≥90 mmHg，且伴有下列任意1项：
   - 尿蛋白≥0.3 g/24h，或尿蛋白/肌酐比值≥0.3，或随机尿蛋白≥(+)；
   - 无蛋白尿但伴有以下靶器官损害：血小板减少（<100×10^9/L）、肝功能损害（血清转氨酶升高2倍以上）、肾功能损害（血肌酐>97 μmol/L）、肺水肿、新发中枢神经系统异常或视觉障碍。
3. **重度子痫前期关键指标**: 血压持续≥160/110 mmHg，或伴严重头痛视物模糊、持续性上腹剧痛、血小板持续下降。

## 三、 降压治疗与母胎保护
1. **降压目标**: 收缩压控制在 130~140 mmHg，舒张压控制在 80~90 mmHg。不可降压过快过低（舒张压不低于80 mmHg）以防胎盘灌注锐减。
2. **首选口服降压药物**:
   - 盐酸拉贝洛尔片（口服，首选）；
   - 硝苯地平片/缓释片（口服）；
   - 甲基多巴（中枢性降压药，长期安全性良好）。
3. **绝对用药红线**:
   - **严禁使用 ACEI、ARB 及 ARNI**！妊娠中晚期使用可引起胎儿肾发育不全、少尿、羊水过少、肺发育不良、颅骨骨化障碍及胎死宫内！
   - 利尿剂（氢氯噻嗪、呋塞米）一般不推荐常规使用，因其进一步缩减母体血容量加重胎盘缺血。
4. **子痫抽搐预防与控制**: 硫酸镁是预防和控制子痫发作的首选解痉药物，静脉负荷后持续滴注，密切监测膝反射、呼吸及尿量。
