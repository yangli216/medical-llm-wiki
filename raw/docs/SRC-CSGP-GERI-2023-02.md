## 一、 指南背景与多重用药严峻现状

我国已进入深度老龄化社会，65岁及以上老年人中超过三分之二患有2种及以上慢性病（多病共存，Multimorbidity）。在传统的各器官专科就诊模式下，老年患者常在不同专科反复开药，导致药物清单急剧膨胀。

**多重用药（Polypharmacy）**通常定义为：日常长期同时使用 **≥ 5 种药物**（使用 ≥ 10 种药物定义为严重多重用药）。多重用药显著增加药物不良反应（ADR）、药物相互作用（DDI）、老年认知障碍、跌倒骨折、再住院率乃至死亡风险。全科医生作为全人健康照护者，是实施老年慢病共病综合统筹、药物重整与处方精简的核心主体。

## 二、 处方瀑布（Prescribing Cascade）的识别与阻断

指南重点告诫基层全科医生高度警惕**处方瀑布**：即**将前一种药物引起的不良反应误判为新出现的疾病症状，进而开具第二种药物进行治疗，导致不良反应层层叠加的恶性连锁反应**。

### 基层全科门诊常见处方瀑布典型范例：
1. **CCB 钙通道阻滞剂 -> 循环利尿剂**：
   - 使用氨氯地平扩血管引起下肢凹陷性水肿，误判为“心衰加重”或“肾功能减退”，盲目加用呋塞米/氢氯噻嗪，导致老年人脱水、电解质紊乱（低钾/低钠）及体位性低血压跌倒。
2. **胆碱酯酶抑制剂 -> 抗胆碱药**：
   - 使用多奈哌齐治疗阿尔茨海默病引起尿失禁，误判为老年神经源性膀胱加用索利那新（抗胆碱药），对抗中枢乙酰胆碱疗效，加重认知减退。
3. **NSAIDs 镇痛药 -> 降压药**：
   - 使用布洛芬/双氯芬酸钠治疗关节痛引起水钠潴留和肾素血管阻力升高导致血压反弹，误判为“高血压恶化”而盲目增加降压药物剂量。

## 三、 老年人潜在不适当用药（PIM）筛查标准

指南推荐基层推广应用中国版老年人 PIM 标准结合国际 Beers 标准与 STOPP/START 准则：

| 药物大类 | 潜在不适当用药表现 (PIM) | 替代或规避建议 |
| :--- | :--- | :--- |
| **镇静催眠药** | 长效苯二氮䓬类（地西泮、氯硝西泮）：半衰期极长，老年蓄积导致镇静过度、共济失调、**跌倒骨折风险增加数倍** | 规避使用；首选非药物认知行为疗法（CBT-I）或小剂量褪黑素受体激动剂 |
| **第一代抗组胺药** | 扑尔敏（氯苯那敏）、苯海拉明：抗胆碱能效应强，引起口干、视物模糊、尿潴留、便秘及认知错乱 | 选用无抗胆碱活性的第二代外周抗组胺药（氯雷他定、西替利嗪） |
| **强抗胆碱能药物** | 氯丙嗪、阿米替林、阿托品类制剂：老年痴呆加重与青光眼急性发作 | 换用 SSRI 类新型抗抑郁药物 |
| **消化道抑酸药** | 长期超疗程（>8~12周）无适应证口服 PPI：胃酸过低导致**艰难梭菌肠炎、肺部感染、维生素B12与钙吸收障碍（骨质疏松）** | 明确适应证，根除幽门螺杆菌后或溃疡愈合后及时减量或停药 |
| **降糖药物** | 强效长效磺脲类（格列本脲）：代谢慢，极易引发老年**致死性难治性低血糖** | 老年人严禁使用格列本脲；优先选用二甲双胍、DPP-4i 或 SGLT2i |

## 四、 处方精简（Deprescribing）五步临床操作法

处方精简是指在专业医疗指导下，对无适应证、潜在损害大于获益、或不符合患者生命终末期意愿的药物进行有计划的剂量递减或终止停用过程。

```mermaid
flowchart LR
    Step1[第1步: 药物重整\n棕色药袋法全面盘点] --> Step2[第2步: 识别PIM\n筛查不适当用药与处方瀑布]
    Step2 --> Step3[第3步: 权衡风险\n结合预期寿命与治疗目标]
    Step3 --> Step4[第4步: 制定计划\n每次减停1种/分步递减]
    Step4 --> Step5[第5步: 动态监测\n防范停药反跳与病情反复]
```

1. **第 1 步：全面药物重整（Brown-Bag Review 棕色药袋法）**：
   - 嘱患者将家中正在服用的所有药品（处方药、非处方 OTC 药、保健品、中成药）全部装入一个袋中带至门诊，逐一核对真实服药依从性与重复成分。
2. **第 2 步：识别潜在不适当用药与处方瀑布**：
   - 逐项审查每种药物是否仍具备明确的现代循证医学适应证。
3. **第 3 步：个体化权衡获益与风险**：
   - 评估起效时间（Time-to-Benefit, TTB）与患者预期寿命（Life Expectancy）。例如对于预期寿命 <1~2 年的终末期高龄衰弱患者，强化降脂（他汀一级预防）或过严降糖（HbA1c <7.0%）的长期心血管获益难以兑现，反而增加肌痛与严重低血糖风险。
4. **第 4 步：制定分级停药计划并与患者达成共识**：
   - 遵循“**每次只减停一种药物、缓慢阶梯式减量**”原则，严禁一次性骤停多种中枢或心血管药物（防止严重停药综合征或反跳）。
5. **第 5 步：随访监测与应急预案**：
   - 停药后 1~2 周专科或电话随访，评估原发病症状有无复发，监测生命体征与生化指标。
