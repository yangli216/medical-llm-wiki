# 诊断学（第9/10版·国家卫生健康委员会规划教材）

## 权威元数据
- 来源代码: SRC-PMPH-DIAG-2024-01
- 权威机构: 人民卫生出版社 / 全国高等医药教材建设研究会 / 国家卫生健康委员会规划教材编写组
- 主编: 万学红、卢雪峰、陈文彬、潘祥林 等
- 出版年份: 2024
- 学科分类: 临床诊断学 / 症状学 / 实验诊断 / 物理检查

## 核心内容要点
1. 常见症状问诊方法学（OLDCARTS模型：起病、部位、性质、程度、持续时间、伴随症状、诱因与缓解因素）。
2. 门诊高发急危重症“红旗征”（Red Flags）强制阻断排查链：
   - 急腹症致命排雷（板状腹、穿孔、绞窄性肠梗阻、宫外孕破裂、休克）；
   - 胸痛致命五联征（急性冠脉综合征、主动脉夹层、肺栓塞、张力性气胸、心包填塞）；
   - 头痛颅内高压与脑膜刺激征（剧烈霹雳样头痛、喷射性呕吐、Kernig/Brudzinski征）；
   - 呼吸困难危急识别（端坐呼吸、哮鸣音伴发绀、喉头水肿）。
3. 典型物理查体与体征（McBurney征、Murphy征、脑膜刺激征、移动性浊音、巴宾斯基征等）。
4. 症状鉴别诊断树（从主诉出发的逐步收窄推导逻辑）。
