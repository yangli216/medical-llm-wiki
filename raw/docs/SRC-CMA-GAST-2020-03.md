# 《中国慢性胃炎共识意见（2020年，上海）》规范全文要点

## 一、 基本信息与学术权威
- **发布机构**：中华医学会消化病学分会
- **发表刊物**：《中华消化杂志》2020年第40卷
- **核心定位**：我国慢性胃炎、萎缩性胃炎与肠化生胃癌二级预防全流程管理的临床共识。

## 二、 诊断与病理风险评估
1. **病因学核心**：幽门螺杆菌 (Hp) 感染是慢性胃炎和慢性萎缩性胃炎最核心病因（Correa 级联学说：正常黏膜 -> 非萎缩性胃炎 -> 萎缩性胃炎 -> 肠化生 -> 异型增生 -> 胃癌）。
2. **内镜与活检规范**：
   - 白光内镜结合窄带成像放大内镜 (ME-NBI) 精准靶向活检；
   - 国际 OLGA/OLGIM 胃炎分期系统：中重度萎缩伴广泛肠化生 (OLGA/OLGIM III~IV级) 是胃癌高危病变。
3. **监测随访时间窗**：
   - 局限性轻度萎缩无肠化生：每 3 年胃镜复查；
   - 中重度萎缩或伴广泛肠化生：每 1~2 年内镜精查；
   - 低级别上皮内瘤变（轻度异型增生）：6~12 个月内镜精查；高级别上皮内瘤变：即刻内镜黏膜下剥离术 (ESD) 根治切除。

## 三、 临床治疗规范
1. **根除幽门螺杆菌**：根除 Hp 是延缓甚至逆转胃黏膜萎缩、阻断胃癌进展的最重要二级预防措施。
2. **对症与胃黏膜保护**：伴反酸烧心选用 PPI/P-CAB；伴胆汁反流选用铝碳酸镁；伴消化不良选用促胃动力药（莫沙必利）。
3. **化学预防与抗氧化**：适量补充叶酸、维生素 C、维生素 E 对改善胃黏膜化生具有辅助获益。
