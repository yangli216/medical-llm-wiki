# 《急性胆囊炎诊治指南（2021版）》规范全文要点

## 一、 基本信息与学术权威
- **发布机构**：中华医学会外科学分会胆道外科学组
- **发表刊物**：《中华外科杂志》2021年
- **核心定位**：急性结石性与非结石性胆囊炎 TG18 分级、解痉镇痛对症与早期腹腔镜切除指南。

## 二、 核心临床要点
1. **典型体征与超声**：右上腹阵发性绞痛向右肩背放射、Murphy征阳性；超声示胆囊壁厚≥4mm、结石嵌顿。
2. **对症解痉**：首选间苯三酚与非甾体抗炎药；严禁单用吗啡防Oddi括约肌痉挛。
3. **手术时机**：发病 72 小时内早期首选急诊腹腔镜胆囊切除术（LC）。
