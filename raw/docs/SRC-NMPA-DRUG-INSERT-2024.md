# 《国家药品监督管理局 (NMPA) 官方核准药品说明书汇编》

- 发布机构：国家药品监督管理局 (NMPA) / 国家药品审评中心 (CDE)
- 数据版本：2024年国家法定核准药品说明书数据库
- 适用范围：全国各级医疗机构临床医师、药师、合理用药审方系统及门诊处方审核

## 一、 官方核准药品说明书的法定地位与规范原则
药品说明书是载明药品重要科学数据、法定指导医师临床处方和患者安全用药的核心技术法规文件。根据《中华人民共和国药品管理法》及《药品说明书和标签管理规定》：
1. **法定效应**：经国家药品监督管理局核准的药品说明书具有最高法律效力与临床指导权威性；
2. **核心要素**：必须严格包含药品通用名称、成分、性状、适应症、规格、用法用量、不良反应、禁忌、注意事项、孕妇及哺乳期妇女用药、儿童用药、老年用药、药物相互作用、药物过量、药理毒理、药代动力学、贮藏及有效期限；
3. **安全底线**：严禁超适应症、超极量使用；对存在严重毒副反应、黑框警告或特殊人群禁忌的品种，必须在处方系统实施前置拦截与审核。

## 二、 基层门诊核心药品类别覆盖
本汇编聚焦中国基层卫生医疗机构与综合医院门诊高频处方的核心基本药物，涵盖：
1. **心血管系统药物**：钙通道阻滞剂（氨氯地平、硝苯地平控释片）、RAS抑制剂（缬沙坦、氯沙坦、厄贝沙坦、依那普利）、β受体阻滞剂（美托洛尔、比索洛尔）、利尿剂（氢氯噻嗪、吲达帕胺）等；
2. **内分泌与代谢系统药物**：双胍类（二甲双胍）、磺脲类（格列美脲）、α-糖苷酶抑制剂（阿卡波糖）、SGLT2抑制剂（达格列净）、DPP-4抑制剂（利格列汀）、甲状腺用药（左甲状腺素钠、甲巯咪唑）、他汀类降脂药（阿托伐他汀、瑞舒伐他汀）、降尿酸药（别嘌醇）等；
3. **呼吸与抗过敏系统药物**：吸入复方制剂（布地奈德福莫特罗、沙美特罗替卡松）、短效支气管舒张剂（沙丁胺醇、异丙托溴铵）、白三烯受体拮抗剂（孟鲁司特钠）、祛痰药（氨溴索）、抗组胺药（氯雷他定、西替利嗪）等；
4. **消化系统药物**：质子泵抑制剂（奥美拉唑、雷贝拉唑）、胃黏膜保护剂及铋剂（枸橼酸铋钾、果胶铋）、抗感染胃药（阿莫西林、克拉霉素）、止泻吸附药（蒙脱石散、小檗碱）等；
5. **骨科镇痛与抗炎药物**：非甾体抗炎药（布洛芬缓释胶囊、双氯芬酸钠缓释片、塞来昔布、依托考昔）、钙与维生素D制剂（碳酸钙D3、骨化三醇）、抗骨质疏松药（阿仑膦酸钠）等；
6. **神经与精神系统药物**：抗血小板药（阿司匹林肠溶片、氯吡格雷）、脑血管保护剂（丁苯酞）、抗抑郁与焦虑药（艾司西酞普兰、舍曲林）、镇静催眠药（艾司唑仑、唑吡坦）等；
7. **泌尿生殖系统药物**：α1受体阻滞剂（坦索罗辛）、5α还原酶抑制剂（非那雄胺）、促尿酸排泄药（苯溴马隆）等；
8. **抗感染与皮肤外用药物**：口服抗菌药（头孢克肟、左氧氟沙星、莫西沙星）、外用制剂（莫匹罗星、硝酸咪康唑、氢化可的松）等；
9. **急症与急救制剂**：抗心绞痛急救药（硝酸甘油片）、暴露免疫制剂（人用狂犬病疫苗、狂犬病人免疫球蛋白）等。

## 三、 CDSS与智能审方核心审核规则
1. **绝对禁忌拦截**：妊娠期禁用药物（如 ACEI/ARB、他汀类、沙利度胺等）、严重过敏史品种、重度器官功能衰竭禁忌品种；
2. **极量超限拦截**：严格监测单次剂量及日最大给药剂量（如对乙酰氨基酚日剂量严禁超过 2000mg）；
3. **严重相互作用（DDI）拦截**：严禁硝酸酯类药物与 PDE-5 抑制剂合用；严禁双重 RAS 系统阻断；严禁他汀类与吉非罗齐联用；严禁大环内酯类与易致 QT 间期延长药物联用；
4. **特殊人群剂量折算**：针对肾功能不全（以 eGFR 梯级为依据）、肝功能不全、高龄老年人及儿童实施精确剂量滴定。
