# 中国心力衰竭诊断和治疗指南（2024）

- **文献标识**: SRC-CMA-CARD-2024-02
- **制定机构**: 中华医学会心血管病学分会 / 中国医师协会心力衰竭专业委员会
- **刊发刊物**: 《中华心血管病杂志》2024年第52卷 / 中华医学会官方发文
- **发布年份**: 2024年

---

## 一、 指南概述与主要更新

心力衰竭是各种心血管疾病的终末阶段，也是全球及我国面临的最重大公共卫生挑战之一。《中国心力衰竭诊断和治疗指南（2024）》对我国心衰的分类诊断标准、生物标志物评估、器械治疗以及药物治疗路径进行了革命性更新。最核心的突破是：确立了以 **“新四联”药物（ARNI/ACEI + β受体阻滞剂 + MRA + SGLT2i）** 为核心的射血分数降低心衰（HFrEF）基石治疗方案，并明确了 SGLT2抑制剂 在射血分数保留心衰（HFpEF）中的划时代疗效。

---

## 二、 心力衰竭定义与表型分型

心衰是一种复杂的临床综合征，由各种心脏结构或功能异常引起心室充盈或射血功能受损所致。根据左心室射血分数（LVEF），指南将心力衰竭分为四大临床表型：

| 心衰临床表型 | 缩写 | LVEF 诊断界值 | 结构性改变与生物标志物辅助证据 |
| :--- | :--- | :--- | :--- |
| **射血分数降低的心力衰竭** | **HFrEF** | **≤ 40%** | 左心室腔扩大、收缩功能明显减退 |
| **射血分数轻度降低的心力衰竭** | **HFmrEF** | **41% ~ 49%** | 左心房/左心室重构、舒张功能受损、利钠肽升高 |
| **射血分数保留的心力衰竭** | **HFpEF** | **≥ 50%** | 舒张功能不全（E/e'升高）、左房扩大或LVH、利钠肽显著升高 |
| **射血分数改善的心力衰竭** | **HFimpEF** | **随访时 > 40%** | **基线 LVEF ≤ 40%，经治疗后复查 LVEF > 40% 且绝对值较基线提升 ≥ 10%** |

*注：对于 HFimpEF 患者，即便心功能与射血分数完全恢复正常，仍严禁盲目停用抗心衰基石药物，以防心室逆重构恶化与复发。*

---

## 三、 生物标志物诊断界值（利钠肽 BNP / NT-proBNP）

利钠肽是心衰诊断、病情评估、排除诊断及预后判定的核心标志物：
1. **慢性心力衰竭排除切点（高阴性预测价值）**：
   - BNP < 35 pg/mL 或 NT-proBNP < 125 pg/mL（心衰可能性极低）。
2. **急性心力衰竭诊断切点**：
   - BNP ≥ 100 pg/mL；
   - **NT-proBNP（年龄分层诊断阈值）**：
     - < 50 岁：NT-proBNP ≥ 450 pg/mL
     - 50 ~ 75 岁：NT-proBNP ≥ 900 pg/mL
     - > 75 岁：NT-proBNP ≥ 1800 pg/mL
     - 肾功能不全（eGFR < 60 mL/min/1.73m²）：NT-proBNP ≥ 1200 pg/mL

## 四、 HFrEF 药物治疗：“新四联”基石方案（GDMT）

指南强烈推荐，所有无禁忌证的 HFrEF 患者，应尽早启动由4类药物组成的“新四联”方案，全方位阻断神经内分泌系统并逆转心室重构，显著降低心血管死亡与心衰住院率：

### 1. 血管紧张素受体脑啡肽酶抑制剂（ARNI）或 ACEI/ARB
- **ARNI（沙库巴曲缬沙坦）**：**首选推荐**（I类推荐，A级证据）。优于传统ACEI，能显著降低全因死亡与心衰再住院。
- **ACEI/ARB**：仅在无法耐受 ARNI 或存在相关禁忌时选用。
- **安全用药警示**：由 ACEI 更换为 ARNI 时，**必须严格停用 ACEI 至少 36 小时**，方可启动 ARNI，以彻底规避缓激肽代谢蓄积引发严重血管神经性水肿；有血管神经性水肿病史者绝对禁用。

### 2. β受体阻滞剂
- **推荐品种**：经循证验证的3种药物——**琥珀酸美托洛尔缓释片、富马酸比索洛尔、卡维地洛**（I类推荐，A级证据）。
- **给药原则**：在患者病情相对稳定、无严重水钠潴留及急性失代偿状态下，从小剂量起始，每2~4周倍增一次，逐步滴定至靶剂量或最大耐受剂量。

### 3. 盐皮质激素受体拮抗剂（MRA）
- **代表药物**：螺内酯（Spironolactone）、依普利酮。
- **给药监测**：使用期间需密切监测血清钾和肾功能。若血钾 > 5.0 mmol/L 或 eGFR < 30 mL/min/1.73m²，需减量或停药，防范严重高钾血症。

### 4. 钠-葡萄糖共转运蛋白2抑制剂（SGLT2i）
- **代表药物**：**达格列净（10 mg qd）、恩格列净（10 mg qd）**（I类推荐，A级证据）。
- **划时代地位**：**无论患者是否合并2型糖尿病，均强烈推荐应用**。降心衰住院及心血管死亡获益出现迅速（最快数周即可见效），耐受性好，不引起低血糖。

## 五、 利尿剂与容量管理规范

- **利尿剂地位**：是唯一能充分控制心衰液体潴留、迅速消除肺淤血及外周水肿的药物。
- **首选药物**：袢利尿剂（呋塞米、托拉塞米、布美他尼）。
- **治疗目标**：快速消除水肿，达到“干体重”（无液体潴留体征），随后调整为维持剂量，长期维持出入水量平衡。
- **利尿剂抵抗对策**：增加袢利尿剂静脉剂量或改持续静脉滴注；联合噻嗪类利尿剂（双重肾单位阻滞）；联合新一代血管加压素V2受体拮抗剂（托伐普坦）。
