# 慢性阻塞性肺疾病诊治指南（2021年修订版及最新规范）

- **文献标识**: SRC-CMA-RESP-2021-01
- **制定机构**: 中华医学会呼吸病学分会慢阻肺学组
- **刊发刊物**: 《中华结核和呼吸杂志》2021年第44卷 / 中华医学会官方发文
- **发布年份**: 2021年（结合GOLD最新指南持续跟踪）

---

## 一、 指南概述与主要内容

慢性阻塞性肺疾病（Chronic Obstructive Pulmonary Disease, COPD，简称慢阻肺）是我国最为高发且致死率极高的慢性呼吸系统疾病。据中国肺部健康研究（CPH）统计，我国20岁及以上人群慢阻肺患病率为8.6%，40岁以上人群高达13.7%，总患病人数近1亿。《慢性阻塞性肺疾病诊治指南（2021年修订版）》全面确立了以“早筛早诊早治、规范肺功能检查、以支气管舒张剂为核心基石、精准分型选用吸入糖皮质激素（ICS）”为纲领的诊疗标准。

### 核心诊疗准则：
1. **诊断金标准**：明确吸入支气管舒张剂后 **FEV1/FVC < 0.70** 为确立持续不可逆气流受限的法定唯一定义。
2. **综合评估升级**：将单一肺功能分级拓展为融合“肺功能受损度（GOLD 1-4）+ 症状负荷（CAT/mMRC）+ 未来急性加重风险（A/B/E分组）”的三维立体评估体系。
3. **双支气管舒张剂（LABA+LAMA）成为治疗中流砥柱**：超越以往单支扩剂或盲目ICS三联，明确双支扩剂是缓解呼吸困难和预防加重的一线推荐。
4. **ICS精准应用阈值（血嗜酸性粒细胞EOS计数）**：正式确立将外周血嗜酸性粒细胞计数（EOS）作为启用或撤出吸入激素的关键生物标志物。

## 二、 诊断标准与肺功能评估

### 1. 临床诊断标准
在具备慢性咳嗽、咳痰、进行性呼吸困难等临床表现，以及长期吸烟、室内生物燃料燃烧、职业粉尘暴露等危险因素背景下：
- **诊断金标准**：在吸入短效支气管舒张剂（沙丁胺醇 400 μg）15~20分钟后，行肺功能检查：
  - **FEV1 / FVC < 0.70（即 < 70%）**。
  - 即可确立存在持续不完全可逆的气流受限，明确诊断为慢阻肺。

### 2. 气流受限严重程度分级（基于用药后 FEV1 占预计值百分比）：
- **GOLD 1 级（轻度）**：FEV1 % pred ≥ 80%
- **GOLD 2 级（中度）**：50% ≤ FEV1 % pred < 80%
- **GOLD 3 级（重度）**：30% ≤ FEV1 % pred < 50%
- **GOLD 4 级（极重度）**：FEV1 % pred < 30%

## 三、 稳定期综合评估体系（ABE 分组模型）

根据患者日常生活症状负荷（评估测试CAT量表或呼吸困难问卷mMRC）以及过去1年内的急性加重史，分为三类核心干预组别：

| 综合分组 | 过去 1 年急性加重病史 | 症状负荷（CAT / mMRC） | 初始推荐药物方案 |
| :--- | :--- | :--- | :--- |
| **A 组** | 0 次或 1 次中度加重（未导致住院） | CAT < 10 分 或 mMRC 0~1 级（症状轻） | 单支气管舒张剂（SABA/SAMA/LABA/LAMA） |
| **B 组** | 0 次或 1 次中度加重（未导致住院） | CAT ≥ 10 分 或 mMRC ≥ 2 级（症状重） | **长效双支扩联合（LABA + LAMA）** |
| **E 组** | **≥ 2 次中度加重 或 ≥ 1 次导致住院加重** | 不论症状严重程度（高急性加重风险） | **长效双支扩（LABA + LAMA）**；若伴血EOS ≥ 300 /μL，首选 **三联吸入制剂（LABA + LAMA + ICS）** |

---

## 四、 药物治疗路径与吸入制剂阶梯规范

### 1. 长效支气管舒张剂（治疗核心基石）
- **长效抗胆碱能药（LAMA）**：噻托溴铵（Tiotropium）、乌美溴铵（Umeclidinium）、阿地溴铵。阻断M3受体，持久舒张气道平滑肌，降低急性加重率优于单用LABA。
- **长效β2受体激动剂（LABA）**：茚达特罗（Indacaterol）、福莫特罗（Formoterol）、沙美特罗（Salmeterol）。激活腺苷酸环化酶，迅速并持久扩张支气管。
- **双支扩复方制剂（LABA + LAMA）**：如乌美溴铵/维兰特罗、茚达特罗/格隆溴铵。协同互补靶向不同气道受体，带来更强肺功能改善与生活质量提升。

### 2. 吸入糖皮质激素（ICS）的应用指征与生物标志物
**严禁单药使用 ICS（必须联合 LABA 或 LABA+LAMA）**。
- **强烈推荐启用 ICS（三联方案 LABA+LAMA+ICS）**：
  - 过去1年内发生 ≥ 1次因急性加重住院，且外周血 **EOS ≥ 300 /μL**；
  - 合并支气管哮喘病史或哮喘-慢阻肺重叠（ACO）。
- **可考虑启用 ICS**：
  - 过去1年内发生 ≥ 2次中度急性加重，且外周血 **100 ≤ EOS < 300 /μL**。
- **反对使用 / 应考虑撤出 ICS**：
  - 外周血 **EOS < 100 /μL**；
  - 反复发作临床肺炎（Pneumonia）；
  - 既往有活动性肺结核或非结核分枝杆菌肺病感染史。

### 3. 非药物关键干预
1. **戒烟**：目前唯一被证实能够切实减缓FEV1年递减率的根本性干预手段。
2. **长期家庭氧疗（LTOT）**：严重静息低氧血症（PaO2 ≤ 55 mmHg 或 SaO2 ≤ 88%）患者，每日吸氧时间需 ≥ 15 小时。
3. **长期无创正压通气（NIV/BiPAP）**：重度高碳酸血症（PaCO2 ≥ 53 mmHg）的稳定期患者可降低再住院率。
4. **预防接种**：每年接种流感病毒疫苗，定期接种23价肺炎球菌多糖疫苗。
