# 中国高血压防治指南（2024年修订版）

- **文献标识**: SRC-CMA-CARD-2024-01
- **制定机构**: 中华医学会心血管病学分会 / 中国高血压联盟 / 国家心血管病中心
- **刊发刊物**: 《中华高血压杂志》2024年第32卷第7期 / 《中华心血管病杂志》
- **发布年份**: 2024年

---

## 一、 指南概述与主要修订背景

《中国高血压防治指南（2024年修订版）》是在2018年版指南基础上，结合我国高血压流行病学最新特征、近6年国内外高血压高质量循证医学证据进行全面修订的国家级权威专科指南。本指南重点强调基于高血压的“分级、分期、分型”原则进行全面评估和全生命周期管理，以进一步提高我国高血压的知晓率、治疗率和控制率。

### 核心修订要点概览：
1. **诊断标准确立**：坚持以诊室血压 ≥140/90 mmHg 作为我国成人高血压的诊断切点，同时全面强化诊室外血压（动态血压与家庭自测血压）在诊断和疗效评估中的法定地位。
2. **测量工具革新**：明确淘汰水银柱血压计，全面推荐经过国际标准验证的上臂式全自动电子血压计。
3. **心血管危险因素扩充**：新纳入“心率增快”（静息心率 >80 次/分）与“高尿酸血症”作为高血压相关重要心血管危险因素。
4. **降压达标理念强化**：提出对一般患者（含65~79岁老年人）在耐受前提下更积极地降至 <130/80 mmHg。
5. **药物推荐谱扩展**：在传统五大类常规降压药（CCB、ACEI、ARB、利尿剂、β受体阻滞剂）基础上，明确肯定血管紧张素受体脑啡肽酶抑制剂（ARNI）在原发性高血压治疗中的推荐地位。

## 二、 诊断标准与血压水平定义

### 1. 血压测量与诊断界值
在未使用降压药物的情况下，非同日3次诊室血压测量：
- **诊室血压**：收缩压（SBP）≥140 mmHg 和/或 舒张压（DBP）≥90 mmHg。

**诊室外血压诊断切点（辅助与排查白大衣高血压/隐蔽性高血压）**：
- **家庭自测血压（HBPM）**：平均血压 ≥135/85 mmHg。
- **24小时动态血压监测（ABPM）**：
  - 24小时平均血压 ≥130/80 mmHg；
  - 日间（清醒状态）平均血压 ≥135/85 mmHg；
  - 夜间（睡眠状态）平均血压 ≥120/70 mmHg。

### 2. 血压水平分类与分级（成人）
| 分类 | 收缩压 (mmHg) | | 舒张压 (mmHg) |
| :--- | :--- | :--- | :--- |
| **正常血压** | <120 | 且 | <80 |
| **正常高值** | 120~139 | 和/或 | 80~89 |
| **1级高血压（轻度）** | 140~159 | 和/或 | 90~99 |
| **2级高血压（中度）** | 160~179 | 和/或 | 100~109 |
| **3级高血压（重度）** | ≥180 | 和/或 | ≥110 |
| **单纯收缩期高血压** | ≥140 | 且 | <90 |

## 三、 心血管危险分层体系（分级、分期、分型）

### 1. 心血管危险因素与靶器官损害
- **主要危险因素**：高龄（男性≥55岁，女性≥65岁）、吸烟/被动吸烟、血脂异常、糖耐量受损/空腹血糖受损、早发心血管病家族史、腹型肥胖或BMI≥28 kg/m²、**静息心率增快（>80次/分）**、**高尿酸血症**。
- **靶器官损害（TOD）**：左心室肥厚（心电图或超声心动图）、颈动脉内膜中层厚度（IMT）增厚或动脉粥样斑块、脉搏波传导速度（PWV）升高、微量白蛋白尿（UACR 30~300 mg/g）或估算肾小球滤过率（eGFR 30~59 mL/min/1.73m²）。
- **临床伴发疾病**：脑血管病（缺血性/出血性卒中、TIA）、心脏疾病（心肌梗死、心绞痛、心力衰竭）、糖尿病、重度慢性肾脏病（CKD 4-5期）、外周血管疾病。

### 2. 危险分层标准
根据血压水平、危险因素数目、靶器官损害及临床伴发疾病，综合判定为：**低危、中危、高危、很高危**。只要合并临床伴发疾病或严重靶器官损害，直接列为很高危。

## 四、 降压治疗目标与策略

### 1. 降压目标值
- **一般高血压患者（含65~79岁老年人）**：
  - 第一步目标：降至 **<140/90 mmHg**（I类推荐，A级证据）；
  - 耐受良好目标：建议进一步降至 **<130/80 mmHg**（I类推荐，A级证据）。
- **≥80岁高龄老年人**：
  - 推荐降压目标为 **<140/90 mmHg**（如耐受性良好且无明显体位性低血压，可谨慎个体化评估）。
- **合并糖尿病患者**：推荐目标值 **<130/80 mmHg**（I类推荐，A级证据）。
- **合并冠心病或心力衰竭**：推荐目标值 **<130/80 mmHg**。
- **合并慢性肾脏病（CKD，伴明显蛋白尿UACR>300mg/g）**：目标值推荐 **<130/80 mmHg**。

## 五、 降压药物推荐与联合用药路径

### 1. 基础常规五大类降压药物
1. **二氢吡啶类钙通道阻滞剂（CCB）**：如氨氯地平、硝苯地平控释片、左旋氨氯地平。强效降压，对代谢无不良影响，尤其适合老年高血压、单纯收缩期高血压及合并动脉粥样硬化者。
2. **血管紧张素转换酶抑制剂（ACEI）**：如依那普利、贝那普利、培哚普利。具有确切心肾保护作用，改善胰岛素敏感性，降低蛋白尿。干咳为常见不良反应。
3. **血管紧张素II受体阻滞剂（ARB）**：如氯沙坦、缬沙坦、坎地沙坦、厄贝沙坦。心肾保护作用与ACEI相当，干咳发生率极低，耐受性好。
4. **噻嗪类及样利尿剂**：如氢氯噻嗪、吲达帕胺。适用于老年高血压、难治性高血压、心衰合并高血压。需监测电解质与血尿酸。
5. **β受体阻滞剂**：如琥珀酸美托洛尔缓释片、富马酸比索洛尔、卡维地洛、奈必洛尔。适用于交感神经过度激活、伴心率增快（>80次/分）、合并冠心病或心力衰竭患者。

### 2. 新增推荐：血管紧张素受体脑啡肽酶抑制剂（ARNI）
- **代表药物**：沙库巴曲缬沙坦。
- **机制与地位**：同时抑制脑啡肽酶与阻断AT1受体，增强利钠肽系统并抑制RAS系统。指南正式推荐ARNI作为降压药物，尤其适合合并心力衰竭、左心室重构、蛋白尿肾病及老年高血压患者。

### 3. 联合治疗与单片复方制剂（SPC）
- **起始联合指征**：血压 ≥160/100 mmHg，或高于目标血压 20/10 mmHg 以上，或高危/很高危患者，推荐起始即采用低剂量两种降压药联合治疗（I类推荐，A级证据）。
- **优先推荐的优化联合方案**：
  - `CCB + ACEI` 或 `CCB + ARB`（血管扩张+RAS阻断，互补降压，抵消外周水肿）
  - `ACEI/ARB + 噻嗪类利尿剂`（拮抗利尿剂诱发的RAS激活）
  - `CCB + 噻嗪类利尿剂`
  - `CCB + β受体阻滞剂`
  - `ARNI + CCB`
- **严禁联用方案**：**ACEI 与 ARB 不得联合应用**（增加高钾血症及急性肾损伤风险，无额外临床获益）。
- **推崇单片复方制剂（SPC）**：如氨氯地平贝那普利、缬沙坦氨氯地平、缬沙坦氢氯噻嗪等，可显著提高患者服药依从性与血压达标率。

## 六、 特殊类型高血压与器械治疗

1. **难治性高血压（Resistant Hypertension）**：
   - 定义：在改善生活方式基础上，足量应用包括利尿剂在内的3种不同机制降压药，血压仍未达标；或使用≥4种降压药方能控制。
   - 处理：排查继发性病因及依从性问题后，首选加用醛固酮受体拮抗剂（螺内酯）或阿米洛利、β受体阻滞剂。
2. **经导管去肾交感神经消融术（RDN）**：
   - 经严格排查确诊为难治性高血压、药物不耐受或依从性极差的患者，在经验丰富的中心经充分MDT评估后，可谨慎作为辅助降压手段。
