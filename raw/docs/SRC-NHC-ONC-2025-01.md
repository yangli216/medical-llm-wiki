# 中国结直肠癌诊疗规范（2025版）

- **文献标识**: SRC-NHC-ONC-2025-01
- **制定机构**: 中华人民共和国国家卫生健康委员会医政司
- **刊发刊物**: 国家卫生健康委员会官方发文 / 《中华外科杂志》2025年
- **发布年份**: 2025年

---

## 一、 规范概述与主要更新

结直肠癌（Colorectal Cancer, CRC）是我国常见且发病率呈持续上升趋势的消化道恶性肿瘤。《中国结直肠癌诊疗规范（2025版）》由国家卫生健康委组织全国肿瘤内科、结直肠外科、放疗科、放射诊断学、病理学及内镜学权威专家联合修订。新规范高度聚焦精准医学与微创化理念，将分子病理分型前置指导全身治疗，并在直肠癌中系统推行全程新辅助治疗（TNT）及器官保留策略。

### 核心规范要点：
1. **筛查分层标准化**：推行“初筛问卷危险度评估 + 粪便免疫化学试验（FIT）”联合策略，全结肠镜作为确诊金标准。
2. **高分辨率直肠MRI结构式报告**：强制规范直肠癌术前分期必须精确报告环周切缘（CRM）状态、壁外血管侵犯（EMVI）及腹膜反折位置关系。
3. **免疫治疗地位飞跃**：明确微卫星高度不稳定（MSI-H）/错配修复缺陷（dMMR）晚期患者将免疫检查点抑制剂作为一线绝对首选方案。
4. **全程新辅助治疗（TNT）与保肛器官保留**：局部进展期直肠癌广泛推广TNT模式，对于获得临床完全缓解（cCR）的患者开创性推荐“观察-等待（Watch & Wait）”非手术器官功能保留策略。
5. **微创外科与机器人手术普及**：全直肠系膜切除（TME）与完整结肠系膜切除（CME）质量控制指标标准化。

## 二、 早期筛查与高危人群评估

### 1. 筛查对象与初筛路径：
- **目标人群**：建议一般人群从 **40 岁起** 接受结直肠癌风险评估；高危人群或45岁起全面启动规律筛查。
- **初筛手段**：
  - 危险度问卷评估；
  - **粪便免疫化学试验（FIT）**：每年检测1次；
  - 粪便多靶点DNA检测（适合拒绝结肠镜检查者的高灵敏度辅助筛查）。
- **精筛与诊断**：初筛阳性者必须接受 **全结肠镜检查（Colonoscopy）**，发现腺瘤或息肉行内镜下切除。

---

## 三、 影像学诊断与分子病理必检指标

### 1. 直肠癌术前高分辨率磁共振（MRI）规范：
直肠癌必须行盆腔高分辨MRI平扫与薄层增强扫描，结构式报告必须明确：
- 肿瘤下极距肛缘及齿状线的精确距离；
- **T分期**（壁内浸润深度）与 **N分期**（系膜及侧方淋巴结受累）；
- **环周切缘（CRM）状态**：肿瘤或转移淋巴结距直肠系膜筋膜（MRF）≤ 1 mm 判定为 CRM 阳性（预后不良指标）；
- **壁外血管侵犯（EMVI）**：评分0~4分，EMVI阳性提示高血行远处转移风险。

### 2. 分子病理必检生物标志物（指导全身治疗决策）：
所有确诊为浸润性结直肠癌患者必须进行以下检测：
1. **MMR / MSI 状态**：免疫组化检测4种错配修复蛋白（MLH1、MSH2、MSH6、PMS2），或PCR检测微卫星状态（dMMR / MSI-H 或 pMMR / MSS）。
2. **RAS 基因变异**：检测 KRAS 和 NRAS 的第2、3、4号外显子突变状态（抗EGFR单抗疗效预测的关键反向指标）。
3. **BRAF 突变**：V600E 突变（高侵袭性与不良预后标志）。
4. **HER2 扩增与 NTRK 融合**（晚期罕见突变靶向药物指征）。

## 四、 综合分期与治疗决策规范

### 1. 早期癌（Tis、T1N0M0）
- 浸润局限于黏膜层或黏膜下层浅层（SM1，浸润深度 < 1000 μm）且分化良好者，首选 **内镜下黏膜切除术（EMR）或黏膜下剥离术（ESD）**。
- 若存在脉管侵犯、低分化、黏膜下深层浸润（SM2/SM3）或切缘阳性，必须追加规范的外科根治性切除术。

### 2. 局部进展期结肠癌（cT3-4 或 N+）
- 首选手术：遵循 **完整结肠系膜切除（CME）原则** 的根治性结肠切除术 + D2/D3区域淋巴结清扫。
- 术后辅助化疗：III期及高危II期结肠癌推荐行含奥沙利铂的辅助化疗（CapeOX方案 3~6个月，或 mFOLFOX6方案 6个月）。

### 3. 局部进展期中低位直肠癌（cT3-4 或 N+）
- **全程新辅助治疗（TNT）标准路径**：
  - 模式：长程盆腔放疗（50 Gy / 25次）同步氟尿嘧啶增敏 + 巩固化疗（CapeOX 或 mFOLFOX6 3~4周期）。
  - **评估分流**：
    - 若达到 **临床完全缓解（cCR）**：对于有强烈保肛保器官意愿的患者，可在严密随访监测（每2~3个月内镜及MRI）下实施 **“观察-等待（Watch & Wait）”**，避免永久性造口创伤；
    - 若未达 cCR：行规范的 **全直肠系膜切除术（TME）**。

### 4. 晚期转移性结直肠癌（mCRC，IV期）

#### （1）dMMR / MSI-H 亚型（约占晚期CRC的5%）
- **一线首选**：**PD-1抑制剂单药（如帕博利珠单抗、斯鲁利单抗）**（I类推荐，A级证据）。疗效远超传统化疗，部分患者可实现长期无病生存。

#### （2）pMMR / MSS 亚型（占晚期绝大多数）
- **RAS 基因野生型且 BRAF 野生型患者**：
  - 首选：**化疗（FOLFOX / FOLFIRI）联合 抗EGFR单克隆抗体（西妥昔单抗）**。对于左半结肠癌疗效尤佳。
- **RAS 基因突变型患者**（抗EGFR耐药）：
  - 首选：**化疗（FOLFOX / FOLFIRI）联合 抗VEGF单克隆抗体（贝伐珠单抗）**。
- **不可切除肝/肺转移转化治疗**：若初始技术不可切除但转移灶局限，经系统转化化疗靶向治疗退缩后，由 MDT 评估争取二期转移灶与原发灶联合根治性切除。
