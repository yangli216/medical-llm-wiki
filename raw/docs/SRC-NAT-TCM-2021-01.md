# 中成药临床应用指导原则与中西药联合安全规范

- **文献ID**: SRC-NAT-TCM-2021-01
- **发布机构**: 中华人民共和国国家卫生健康委员会 / 国家中医药管理局
- **发布年份**: 2021
- **性质**: 国家法定临床应用指导原则

## 核心推荐条款
1. **辨病与辨证相结合原则 (I 类指导原则)**:
   - 选用中成药必须以中医辨证施治为基础，结合现代医学明确诊断；证候相符方能用药，严禁盲目按西医病名套用与证候相逆的中成药。
2. **中西药合用重复成分与毒副蓄积阻断 (I 类强行红线)**:
   - 严禁含西药成分中成药与同类西药叠加：
     - 消渴丸（每10丸含格列本脲 2.5mg）严禁与磺脲类降糖药合用，防致死性严重低血糖昏迷；
     - 感冒灵颗粒、维C银翘片（含对乙酰氨基酚）严禁与泰诺、百服宁、散利痛等西药感冒退热药叠加，防暴发性急性肝坏死衰竭。
3. **中西药理化配伍禁忌 (I 类强行红线)**:
   - 含金属离子（钙、铁、铝、镁）中成药（如牛黄解毒片、石膏类）与喹诺酮类或四环素类抗生素同服，螯合沉淀导致抗生素完全失效；
   - 含麻黄中成药（麻黄碱）禁与降压药同服（收缩血管拮抗降压），禁与单胺氧化酶抑制剂合用（高血压危象）。
