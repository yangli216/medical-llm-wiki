# 抗菌药物临床应用指导原则（国卫办医发最新管理规范）

- **文献标识**: SRC-NHC-PHAR-2015-01
- **制定机构**: 中华人民共和国国家卫生健康委员会 / 国家中医药管理局 / 中央军委后勤保障部卫生局
- **刊发刊物**: 国卫办医发官方文件 / 国家法定临床规范
- **发布年份**: 2024年综合修订管理版（国家卫健委医政医管局持续监督考核文件）

---

## 一、 基本原则与制度体系

为规范我国各级医疗机构抗菌药物临床合理应用，有效遏制细菌耐药，国家卫生健康委制定并严格推行《抗菌药物临床应用指导原则》。抗菌药物的临床应用必须严格遵循 **“安全、有效、经济”** 三大基石原则，实行全院处方权限动态考核与责任制管控。

### 核心管理准则：
1. **诊断指征严格化**：仅在诊断为细菌、真菌等敏感病原微生物感染时方具有用药指征；病毒感染（如普通感冒、单纯疱疹、无并发症的病毒性流感等）**严禁使用抗菌药物**。
2. **“先送检、后用药”黄金法则**：在启动抗菌药物治疗前，必须规范采集合格的临床标本（血、痰、尿、脑脊液、穿刺液）送病原学涂片、培养与药敏试验，作为目标治疗和降阶梯调整的法律与临床依据。
3. **经验治疗向目标治疗有序转换**：初始经验性覆盖在48~72小时后，应根据临床反应及药敏结果迅速调整为针对性狭谱抗菌药物。
4. **围手术期预防用药时限极简化**：清洁（I类）切口严格限制预防指征，给药时限严格控制在术前0.5~1小时及术后24小时以内。

## 二、 抗菌药物临床分级管理制度

医疗机构必须对抗菌药物临床应用实行严格的三级分级管理，根据药物的安全性、疗效、细菌耐药风险及价格划定：

### 1. 非限制使用级抗菌药物
- **定义**：经长期临床应用证明安全、有效，对细菌耐药性影响较小，价格相对较低的常见品种（如阿莫西林、头孢氨苄、头孢唑林、青霉素、红霉素等）。
- **处方权限**：具有处方权的各级执业医师（含初级专业技术职称住院医师）均可独立开具。

### 2. 限制使用级抗菌药物
- **定义**：经临床长期应用证明安全有效，但对细菌耐药性有较明显影响、不良反应较明显或价格相对较高的品种（如头孢曲松、头孢噻肟、头孢呋辛、左氧氟沙星、莫西沙星、阿奇霉素静脉制剂等）。
- **处方权限**：必须由 **主治医师及以上专业技术职务** 的执业医师方可开具；住院医师在急诊或夜间值班时开具不得超过1日用量，并需次日补签。

### 3. 特殊使用级抗菌药物（最高管控级别）
- **代表药品**：
  - 碳青霉烯类（亚胺培南/西司他丁、美罗培南、厄他培南）；
  - 糖肽类（万古霉素、去甲万古霉素、替考拉宁）；
  - 恶唑烷酮类（利奈唑胺）；
  - 环脂肽类（达托霉素）；
  - 多黏菌素类（多黏菌素B、多黏菌素E）；
  - 甘氨酰环素类（替加环素）；
  - 新型抗假单胞菌或抗耐药菌复方酶抑制剂制剂（如头孢他啶/阿维巴坦）。
- **严格准入与使用规则**：
  1. **处方资质限制**：仅限 **副主任医师及以上专业技术职务** 的医师方有权开具。
  2. **多学科会诊必经程序**：临床应用前必须经由 **感染科专科医师** 或 **临床药师** 会诊同意并签字生效。
  3. **门诊全面禁令**：特殊使用级抗菌药物 **严禁在门诊处方中使用**。
  4. **紧急越级使用规定**：遇急危重症患者严重感染且无法及时会诊时，可越级使用1次（处方量不得超过1日），但必须在24小时内补办专科会诊与补签手续。

## 三、 围手术期预防用药规范

围手术期预防用药旨在预防手术部位感染（SSI），绝非预防全身感染。

### 1. 手术切口分类与预防指征判定：
| 切口类别 | 特征与手术范例 | 预防用药指征 |
| :--- | :--- | :--- |
| **I 类（清洁切口）** | 手术未进入呼吸道、消化道、尿路及生殖道；无创伤与感染（如甲状腺、乳腺、疝修补、单纯体表肿物） | **原则上不预防使用**。仅在以下情况破例使用：涉及重要器官大手术、异物植入术、高龄或严重免疫低下者 |
| **II 类（清洁-污染切口）** | 手术进入呼吸道、消化道、泌尿道等正常菌群腔道但无明显污染（如胃切除、结直肠切除、胆囊切除、剖宫产） | **必须规范预防用药** |
| **III 类（污染切口）** | 开放性新鲜创伤手术、消化道内容物严重溢出或急性化脓性炎症 | **必须预防/治疗性用药** |
| **IV 类（污秽-感染切口）** | 陈旧性感染创伤、有脓肿形成或内脏穿孔 | **属于治疗性用药，不属于预防用药** |

### 2. 给药时机与维持时限规范：
- **术前给药黄金时间**：在 **皮肤切开前 0.5 ~ 1 小时内** 静脉滴注（若使用万古霉素或氟喹诺酮类，因滴注时间长，应在切开前1~2小时开始滴注），确保切开时创口血药浓度达峰。
- **术中追加用药指征**：手术时间 **> 3 小时** 或术中失血量 **> 1500 mL**，术中必须追加1剂。
- **预防总时限严苛限制**：
  - I类切口预防用药时间 **不得超过 24 小时**。
  - 心脏大血管手术等特高危术式最长延至 48 小时。
  - 严禁术后持续使用抗菌药物数天，此类行为不仅不能降低感染率，反而诱发二重感染与多重耐药菌（MDRO）暴发。

### 3. 预防用药品种选择：
- I类切口针对金黄色葡萄球菌与表皮葡萄球菌，首选 **第一代头孢菌素（头孢唑林）** 或 **第二代头孢菌素（头孢呋辛）**。
- 对头孢类明确过敏者，选用克林霉素或万古霉素。
- **严禁** 将第三代头孢菌素、碳青霉烯类及氨基糖苷类作为I类手术常规预防用药。
