## 一、 指南概述与主要更新

我国成人糖尿病患病率已超过11%，且处于高患病、低知晓、低达标的严峻态势。《中国2型糖尿病防治指南（2024版）》是我国糖尿病防控的最高临床纲领性文件。新版指南紧密契合全球重大临床试验结果与中国人群真实世界循证，确立了“以患者为中心、以器官保护为导向、血糖控制与并发症预防并重”的现代慢病诊疗哲学。

### 核心更新关键点：
1. **诊断标准确立**：维持空腹血浆葡萄糖（FPG）和OGTT 2小时血浆葡萄糖标准，并在具备严格标准化质量控制体系的机构，正式推荐 **糖化血红蛋白（HbA1c）≥6.5%** 作为糖尿病的补充诊断标准。
2. **分层器官保护前置**：对于合并动脉粥样硬化性心血管疾病（ASCVD）、高危心血管风险、心力衰竭（HF）或慢性肾脏病（CKD）的2型糖尿病患者，**无论其HbA1c是否达标，均推荐优先联合具有明确器官保护证据的 SGLT2抑制剂 或 GLP-1受体激动剂**。
3. **二甲双胍一线基石地位稳固**：只要无禁忌证，二甲双胍仍为2型糖尿病药物治疗的绝对首选一线药物，并建议在联合治疗中全程保留。
4. **个体化控糖目标规范**：强化“分层分级设定目标”，坚决规避严重低血糖危害。

## 二、 糖尿病诊断标准

糖尿病诊断基于静脉血浆葡萄糖水平（严禁以末梢毛细血管血糖或尿糖作为确诊依据）。

### 1. 临床确诊切点
符合下列指标之一，并在无急性代谢紊乱（如严重感染、创伤、酮症酸中毒）前提下复测确认：
1. **空腹静脉血浆葡萄糖（FPG）**：**≥ 7.0 mmol/L**（禁食至少8小时）。
2. **口服葡萄糖耐量试验（OGTT 75g）2小时血浆葡萄糖**：**≥ 11.1 mmol/L**。
3. **伴有典型高血糖症状（多饮、多尿、多食、不明原因体重减轻）**：加上**随机静脉血浆葡萄糖 ≥ 11.1 mmol/L**。
4. **糖化血红蛋白（HbA1c）**：**≥ 6.5%**（要求采用通过国家标准化检测认证的方法）。

*注：若无典型高血糖症状，必须在改日进行复测以核实诊断。*

### 2. 糖代谢状态分类表
- **正常血糖**：FPG < 6.1 mmol/L 且 OGTT 2h < 7.8 mmol/L。
- **空腹血糖受损（IFG）**：6.1 ≤ FPG < 7.0 mmol/L 且 OGTT 2h < 7.8 mmol/L。
- **糖耐量减低（IGT）**：FPG < 7.0 mmol/L 且 7.8 ≤ OGTT 2h < 11.1 mmol/L。
- **糖尿病前期（Prediabetes）**：包括 IFG、IGT 或两者兼备（此时心脑血管风险已显著升高）。

## 三、 血糖控制目标体系

### 1. 一般成年非妊娠2型糖尿病患者目标：
- **糖化血红蛋白（HbA1c）**：**< 7.0%**（I类推荐，A级证据）。
- **空腹静脉血糖**：4.4 ~ 7.0 mmol/L。
- **餐后2小时非空腹血糖**：< 10.0 mmol/L。

### 2. 个体化控糖目标分层原则：
- **严格目标（HbA1c < 6.5%）**：
  - 适用于：病程短、年轻、预期寿命长、无显著心脑血管并发症、使用无低血糖风险药物治疗且低血糖感知良好的患者。
- **相对宽松目标（HbA1c < 8.0% 或更高）**：
  - 适用于：高龄、预期寿命有限（<5年）、有严重低血糖病史、合并晚期心血管病、晚期微血管并发症（如CKD 4-5期）、认知功能障碍或严重衰弱的患者。
  - 核心底线：避免高血糖导致的高渗状态、酮症和急性感染，严格防范致命性低血糖。

## 四、 降糖药物治疗路径与药物推荐

### 1. 一线基础治疗
- **生活方式干预**：合理膳食、戒烟限酒、规律有氧运动与抗阻运动，贯穿疾病全程。
- **一线首选用药**：**二甲双胍（Metformin）**（I类推荐，A级证据）。
  - 起始剂量 500 mg/d，随餐服用，逐步滴定至最佳有效剂量 2000 mg/d。
  - 禁忌证与警示：eGFR < 30 mL/min/1.73m² 禁用；eGFR 30~44 mL/min/1.73m² 减量使用（最大1000 mg/d）；碘造影剂检查前后需暂停48小时。

### 2. 心肾靶器官保护用药优先策略（变革性推荐）
若2型糖尿病患者伴有以下情况，**无论其基线HbA1c水平如何，在二甲双胍基础上均应尽早加用具有器官保护证据的药物**：
1. **合并动脉粥样硬化性心血管疾病（ASCVD）或极高危因素**：
   - 首选：**GLP-1受体激动剂（GLP-1RA）**（如司美格鲁肽、度拉糖肽）或 **SGLT2抑制剂（SGLT2i）**（如达格列净、恩格列净）。
2. **合并心力衰竭（HFrEF/HFpEF）**：
   - 首选：**SGLT2抑制剂**（I类推荐，A级证据，显著降低心衰住院与心血管死亡）。
3. **合并慢性肾脏病（CKD，特别伴有UACR升高）**：
   - 首选：**SGLT2抑制剂**（延缓肾功能恶化，降低终末期肾病发生率）；若无法耐受或不适用，优选具有肾脏获益证据的 GLP-1RA 或非甾体盐皮质激素受体拮抗剂（非奈利酮）。

### 3. 常规二联与三联降糖口服药物分类
- **DPP-4抑制剂**（西格列汀、利格列汀）：葡萄糖依赖性促胰岛素分泌，不增加低血糖风险，胃肠耐受性好，中性心血管结局。
- **SGLT2抑制剂**（达格列净、恩格列净、卡格列净）：通过尿糖排泄降糖，兼具减重、降压及心肾保护作用。需警惕泌尿生殖道真菌感染，保证充足饮水。
- **GLP-1受体激动剂**（司美格鲁肽等）：强效降糖、显著减轻体重、降低收缩压及心血管事件。常见恶心、呕吐等胃肠不良反应。
- **噻唑烷二酮类（TZD）**（吡格列酮）：增加胰岛素敏感性，但增加水钠潴留和体重，心衰患者禁用。
- **磺脲类（SU）**（格列美脲、格列齐特缓释片）：强效促泌剂，性价比高，但需密切防范低血糖及体重增加。
- **α-糖苷酶抑制剂**（阿卡波糖）：延缓肠道碳水化合物吸收，适合以碳水为主食的中国人群餐后高血糖管理。

### 4. 胰岛素治疗阶梯
- **基础胰岛素起始**：生活方式加口服降糖药治疗3个月以上HbA1c仍不达标者，可联合甘精胰岛素或德谷胰岛素（起始剂量0.1~0.2 U/kg/d），睡前皮下注射并根据空腹血糖平稳滴定。
- **短期胰岛素强化治疗**：对新诊断且HbA1c ≥ 9.0% 或伴明显高血糖症状的患者，可实施2周至3个月的早期胰岛素强化治疗以挽救胰岛β细胞功能。
