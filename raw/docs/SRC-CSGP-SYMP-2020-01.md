## 一、 指南背景与全科门诊诊疗痛点

“头晕/眩晕”是基层全科医疗机构门诊最常见的主诉之一，占成人门诊就诊量的 5%~10%，在 65 岁以上老年人中高达近 30%。然而在基层临床实践中，长期存在“将所有头晕笼统诊断为‘脑供血不足’或‘颈椎病’，滥用扩血管输液”的严重误区。

本指南旨在指导全科医生建立以**病史问诊四分类、床旁体格检查及红旗征识别为核心**的科学鉴别思维，熟练掌握良性阵发性位置性眩晕（耳石症）的手法复位，早期快速识别危及生命的后循环脑梗死（小脑/脑干卒中）。

---

## 二、 核心症状学四分类鉴别

全科接诊必须通过精准问诊将患者模糊的“头晕”描述界定为以下四种临床亚型之一：

| 症状分型 | 患者典型主诉与感受描述 | 主要受累解剖系统 | 常见临床病因 |
| :--- | :--- | :--- | :--- |
| **眩晕 (Vertigo)** | 感到自身或外界环境在**旋转、翻滚、倾斜或晃动**，常伴恶心、呕吐、面色苍白和出冷汗 | 前庭系统（内耳半规管、前庭神经、脑干前庭核） | **良性阵发性位置性眩晕（耳石症）**、梅尼埃病、前庭神经炎、后循环卒中 |
| **头昏 (Dizziness)** | 头部沉重、昏昏沉沉、发紧发胀、“戴了紧箍咒”，但**无天旋地转感** | 全身系统/精神心理 | 慢性原发性头痛、睡眠剥夺、广泛性焦虑、严重贫血、高血压未受控 |
| **晕厥前兆 (Presyncope)**| 突发眼前发黑（黑矇）、肢体发软无力、即将丧失意识倒地感，平卧后迅速好转 | 心脑血液动力学灌注不足 | 体位性低血压、心动过缓/严重心律失常、血管迷走性反射、低血糖 |
| **不稳感 (Disequilibrium)**| 站立或行走时“像踩在棉花上”、步态蹒跚、摇晃不稳，但坐位或卧位时完全消失 | 深感觉本体感觉/小脑共济 | 帕金森综合征、小脑变性、糖尿病周围神经病变（深感觉减退）、多感官衰退 |

## 三、 耳石症（BPPV）的基层识别与手法复位根治

良性阵发性位置性眩晕（BPPV，俗称“耳石症”）占全科门诊所有眩晕病因的 **40% 以上**，是全科医生必须熟练掌握的“立竿见影根治性技术”：

### 1. 临床特征三要素：
- **诱因明确**：头部空间位置变动瞬间诱发（如床上翻身、仰头晾衣服、低头系鞋带）；
- **持续时间极短**：剧烈旋转性眩晕通常在 **数秒至1分钟内（通常 <30秒）** 迅速缓解消失；
- **伴发眼震**：头位保持不变后眼震在数秒内疲劳消失。

### 2. 激发试验与复位操作：
- **后半规管 BPPV（最常见，占85%~90%）**：
  - **诊断金标准**：**Dix-Hallpike 激发试验**（患者坐位迅速后仰至头悬卧位向一侧偏转45度，诱发出上跳伴向地性旋转眼震）；
  - **治疗首选**：**Epley 手法复位**（通过4步连续头位转换，将游离耳石借助重力导回椭圆囊，单次复位有效率达 80%~90%，无需依赖药物）。
- **水平半规管 BPPV（占10%~15%）**：
  - **诊断金标准**：**仰卧翻头试验（Roll Test）**；
  - **治疗首选**：**Barbecue 翻滚手法复位（连续360度翻身）**。

## 四、 排除致命卒中：床旁 HINTS 三步法与“红旗征”

急性持续性眩晕（急性前庭综合征 AVS）是全科最具挑战性的急症，必须鉴别是良性的**前庭神经炎**还是致命的**后循环脑干/小脑卒中**。临床研究证实，发病24小时内，熟练的床旁 **HINTS 三步检查法（敏感度 >97%）优于急诊头颅 MRI-DWI 弥散成像**（MRI超早期假阴性率可达 12%~20%）：

```mermaid

    A[急性持续性眩晕伴眼震] --> B[床旁 HINTS 检查三步法]
    B --> C{1. 头脉冲试验 HIT}
    C -->|正常阴性 (无纠正扫视)| Danger[提示中枢卒中风险极高!]
    C -->|异常阳性 (眼球有复位扫视)| D{2. 自发眼震特征}
    D -->|双向变向性 / 垂直性| Danger
    D -->|单向固定水平旋转| E{3. 垂直偏斜视 Skew}
    E -->|交替遮盖见垂直跳动| Danger
    E -->|无垂直偏斜| Safe[支持外周性前庭神经炎]
```

### 全科门诊眩晕紧急转诊“红旗征（Red Flags）”：
若头晕/眩晕患者伴有以下任何一项，必须立即启动 120 绿色通道转运上级医院卒中中心：
1. 突发新发剧烈头痛、后枕部刀割样疼痛或颈部强直；
2. 伴有神经系统定位体征：复视、构音障碍（言语不清）、吞咽困难、面瘫、单侧肢体无力或麻木；
3. 伴有严重共济失调：即使睁眼也**完全无法独立站立或行走**，向一侧倾倒；
4. HINTS 检查提示中枢性特征（头脉冲试验正常、方向改变性眼震或存在垂直偏斜）；
5. 伴有胸痛、心悸、呼吸困难或严重低血压（心源性晕厥前兆）。
